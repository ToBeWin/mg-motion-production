# 让背景、主体、材质与字幕属于同一套视觉设计

当用户指出“颜色不高端”“背景和主体不搭”“字幕像贴上去的”时，先检查色彩角色、主体比例和受光关系。高级感不能由某个固定色号、降低所有颜色的饱和度、增加渐变或提高分辨率保证。

## 每条路线定义五个角色

1. **环境色**：内容处于纸张、软件工作面、品牌色场还是摄影空间。高信息密度软件优先平静环境；品牌广告允许鲜明色场；金属和玻璃需要能解释体积的反射环境。
2. **主体色与材质**：主界面、字标或产品必须先被看到。白色界面靠合适的亮度差、边缘和轻微投影与背景分离；银色金属靠反射图案与加工结构分离，不能靠整体压暗或泛白。
3. **强调色**：少量用于品牌母形、操作、引用、选择或重要结构。不要让每个文字层、背景角落和装饰物同时争夺高彩度。
4. **次级信息色**：说明、编号、分隔线使用同一色相家族中的次级值。灰色不等于任意黑色；暖纸上的灰绿、蓝紫界面的冷灰、银色硬件的钢蓝需要分别设计。
5. **旁白字幕色**：是有独立对比要求的阅读层。根据实际字幕区域选择，不继承标题色，也不让九条不同题材共用近黑色加粗白边。

先画关键帧，再审开场、阅读段、转场中点和结尾。场景级色板不能替代镜头级检查。主体与背景都过亮会丢轮廓；都接近中灰会显得浑浊；颜色很多而没有主次会变成装饰拼贴。克制并不要求全部使用同一种灰白摄影棚，强节奏品牌片仍可保留鲜明品牌色。

## 九条路线 v9 的实际做法

| 路线 | 环境与主体关系 | 字幕处理 |
|---|---|---|
| 软件操作发布 | 瓷白光场围绕主界面，冷灰蓝投影，蓝紫只承担交互与引用 | 低饱和鸢尾蓝紫 |
| 软件编辑信息 | 暖白纸面、灰蓝正文、浅紫证据块、柔和引用色 | 与引用系统同族的蓝紫 |
| 空间工作台 | 两份资料完整可见；主界面更大；统一光向、投影和阅读距离 | 灰蓝；底部有独立阅读空间 |
| 强节奏动态字体 | 暖白、钴蓝、柔和鼠尾草绿与雾蓝；保留明显节奏对比 | 浅色场用品牌蓝，钴蓝场用暖白 |
| 克制品牌字排 | 暖纸、灰绿字形、陶土色标点；保持平面编辑风格 | 陶土色，呼应标点 |
| 流动品牌 | 同色系的两条渐变矢量曲线围绕字标，保持中间留白 | 柔和蓝色；不与字标争抢 |
| 金属微距 | 保留已经形成体积的真实金属反射与浅色整机镜头 | 微距用柔白与细小冷色边缘/软影，浅色整机用钢蓝 |
| 光学材质 | 保留玻璃、蓝色轨道与浅色受光环境 | 光学蓝 |
| 硬件结构 | 重配真实灯光和反射旗；银色、陶瓷与低饱和电路板；带接触影的透明底片合成到浅色环境 | 钢蓝，图例与字幕同族 |

这些是对应样片的设计决策，不是所有项目通用的高级配色模板。样片仍是原创概念与动作研究，不能因为配色改良就标记为客户验收或大厂旗舰质量。

## 字幕的具体实施

`assets/flagship-studies/caption-themes.json` 定义每条路线的颜色、字重、位置和逐句例外；`native_delivery.py` 在原生合成中生成可编辑字幕。

- 浅色界面不用统一的黑字粗白描边；在真实画面里选择有足够明度差的品牌相关颜色。
- 材质暗部可用柔白文字。若纹理横穿字形，可用细小、同色温的描边与软影；不能用大黑边、发光或按钮底板弥补未检查的背景。
- 一个语句内保持稳定配色。若必须在同一句中跨明暗场，应根据确切转场时间处理；不要按每帧平均亮度闪烁切换。
- 调整字重和字号后重新检查最长句、底部安全距离、画面标题、操作区和字幕之间的间隔。
- SRT 不存储这些美术样式；原生字幕与烧录 MP4 才体现配色。字幕文本和时间未改时也要在实际导出中复查首尾边界。
- 黑色可有合理的设计用途，但字幕颜色应按场景设计，避免默认统一近黑字幕。

## 工具与返修顺序

1. 保存旧版，列出每条的具体问题与色彩角色。先修构图、主次、背景和受光，再调字幕。
2. 原生渐变、矢量路径、轨道遮罩、预合成、相机与投影由 EffectCraft 处理。高倍预合成要统一坐标与尺寸倍率；混用未缩放的路径会把图形错误挤进半幅画面。
3. 金属材质问题回到 Blender 的灯光、材质和反射环境。v9 第一轮提亮导致银色表面泛白，因此淘汰该试渲并恢复暗反射。若用透明底片，保留真实接触阴影；确认 Alpha 在导出的中间格式和 EffectCraft 内均正确。
4. 保持已有声音与时间结构时，可将原版 AAC 直接复用并核对包数据哈希；这证明声音未改，不代表又完成一次听审。
5. 完整解码、原生字幕颜色/内容/边界、引用路径、关键帧与转场中段分别检查。数值通过、模型审查和用户审美反馈分别记录。

本例硬件原始序列有长阅读停留。只有刚性几何、材质、灯光、相机和运动模糊邻近状态均相同且噪声种子不随帧变时，才可复用相同静帧；运动帧不能插帧或重复帧来冒充完整渲染。
