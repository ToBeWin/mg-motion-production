# 四种软件风格共享的 MG 与交互增强

## 共有制作检查

- 原文、真实控件、后态与成果同属一个任务；授权参考业务可沿用并保留来源和统计口径。
- 输入完整态有阅读时间；逐字或逐行揭示不丢字，插入光标不产生运动模糊重影。
- 输入交接时保持文字等比；前景不透明承托与工作台层序正确，实际中间帧无叠字。
- 指针尖端命中缩放/裁切后的真实热点；到位、按压、释放、响应和音效共享标记。
- 阅读框、路径、放大、滚动一次服务一个信息目标；保留真实工具栏和同源数据。
- 动态字排、遮罩接替、页面分层、空间让位与成果汇聚按语义选择，不只增强鼠标。
- 字幕来自最终发声区间；音乐避让保留词头词尾；同一动作不重复叠加多层提示声。
- 分别记录预演、完整成片、技术检查和用户反馈；调整时间线后重新验证输出。

## 图形组件产品发布 / `graphic-product-pop`

由有辨识度的组件承接操作，再进入真实成果和品牌字排。

- **输入交接：** 真实输入保持正视与等比，提交后由输入承托/文件轮廓接到实际窗口；前景输入不与后景正文同时半透明重叠。
- **指针与引导：** 短距离到位、停顿、按压、反馈；阅读时指针退出重点区域。描线落在文件或控件上，强调完成后交给成果。
- **MG 句式：** 价值字排 → 真实输入 → 提交 → 文件到页面遮罩 → 正视成果 → 分层扇出/回正集合 → 品牌接力。
- **空间与节奏：** 组件动作紧凑，允许较大的尺度反差；正文与数字先正视停稳，再进入轻透视。
- **声音：** 键入轻而稀疏，按压绑定可见动作；展开与收束匹配乐句，文字较长时让音乐降低密度。
- **注意：** 动作、引导、声音服务于当前内容与品牌，避免信息遮挡或伪造产品响应。

## 柔光工作台 / `luminous-workspace`

请求或任务对象持续存在，窗口让位说明输入、依据和成果的关系。

- **输入交接：** 输入条是任务锚点；提交后等比收拢到工作台内或停靠一侧，先保持不透明，再与真实后态完成接替。
- **指针与引导：** 指针、选区、引导线与控件共享父级和坐标；局部放大使用同一源内容，工具栏不随正文滚动。
- **MG 句式：** 完整工作台 → 输入特写 → 同一任务提交 → 主窗口让位 → 依据与成果并置 → 内部滚动/局部阅读 → 成果归位。
- **空间与节奏：** 动作幅度克制但关系明确，镜头接近时不同时滚动与重排；快交接后保留宽松阅读。
- **声音：** 轻触与少量气流提示交接；旁白贴着结果出现，配乐连贯有留白，不给每次窗口移动都加声音。
- **注意：** 动作、引导、声音服务于当前内容与品牌，避免信息遮挡或伪造产品响应。

## 角色/指针导览 / `companion-ui-explainer`

持续向导组织注意力，先定位、再操作、再解释反馈和结果。

- **输入交接：** 聚焦 → 原文字形输入 → 可提交态 → 按压/释放 → 真实后态；步骤条解释过程，不能伪装成后端运行日志。
- **指针与引导：** 区分定位、强调和真实点击；尖端命中热点，按压后再出现响应；讲解目标稳定后才亮出阅读框或路径。
- **MG 句式：** 问题字排 → 向导定位 → 输入与提交 → 真实响应 → 证据展开 → 步骤复盘 → 成果序列 → 品牌收束。
- **空间与节奏：** 指针停稳让观众读，步骤错峰；纯 MG 段交给字排、页面与路径，不让鼠标承担整片表演。
- **声音：** 旁白先说明目标或跟随已出现结果；提示声仅对应可见变化，避免游戏化连击声。
- **注意：** 动作、引导、声音服务于当前内容与品牌，避免信息遮挡或伪造产品响应。

## 实证式产品发布 / `evidence-led-showcase`

少量完整任务证明深度，能力巡览展示广度，成果集合与品牌收束。

- **输入交接：** 问题标题由大字停靠，真实请求聚焦/字形揭示/插入光标/提交，输入前景交接实际窗口。
- **指针与引导：** 提交声绑定原生按压帧；源视频已烘焙的指针不重复叠加；摘要出现不早于对应成果证据。
- **MG 句式：** 岗位问题 → 完整案例 → 真实成果与摘要 → 扩展桥段 → 由慢到快的能力巡览 → 最后一项连续回位矩阵 → 品牌。
- **空间与节奏：** 结果在固定视窗内浏览，标题和摘要给宏观价值；巡览与矩阵采用同一成果 ID，时长由本次内容决定。
- **声音：** 问题、结果与价值分句对应画面，配乐保持连续乐段并避让旁白；结尾留出自然收束。
- **注意：** 动作、引导、声音服务于当前内容与品牌，避免信息遮挡或伪造产品响应。

## 实现与调用

共享可编辑源码位于 `assets/native-interaction/source/effectcraft/`。使用 `rebuild.py` 和本次授权素材构建新片；单行输入构建器与多行输入的实现不同，多行需针对素材另做。规划器会按风格载入组件检查与编排建议。声音和用户验收另行完成。
