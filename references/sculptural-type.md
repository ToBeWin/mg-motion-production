# 字形雕塑＋动态排版

风格 ID：`sculptural-type`。同一个原创字形或品牌母形，连续成为三维实体、平面文字载体和留白空间。体积、字排和空间共同表达品牌主张；观看者能够追踪它如何改变角色。

2026-10-29 用户要求将此风格固化到 Skill，补充场景、制作流程及配乐搭配。随附《映序 / AUREL · 让想象，有形。》v2.1 作为具体案例。认可范围是这一风格的收录；蓝色、字母 A、四个构件、16 秒和钢琴均为本例选择，新项目重新设计。

## 适用场景与内容要求

| 场景 | 怎样应用 | 必须补齐的内容 |
|---|---|---|
| 品牌发布、焕新、字标片头 | 把字标拆解、重组，形成可记住的实体轮廓与落版 | 本次品牌身份、字形使用权、清楚的品牌与口号 |
| 创意 AI、设计软件与内容工具 | 字形进入画布、图层、工具状态，转化为实际作品 | 可见输入、关键操作与真实输出；抽象开场不能代替功能证明 |
| 科技硬件、工业设计品牌 | 以字形的材质、切面和结构接续真实产品 | 产品比例、部件、材质与性能依据；概念造型需注明 |
| 发布会、展览、官网开屏 | 用大轮廓和少量文字建立第一印象 | 观看距离、屏幕比例、静音需求；循环需单独设计接缝 |
| 设计工作室、建筑、文化活动 | 把主题字变为空间、窗框、构造与展陈语言 | 主题和场所特征，避免只换品牌名复用同一字母 |
| 品牌短广告、社交片头 | 缩短构形过程，突出一句主张与一次清楚落版 | 实际卖点或行动信息；竖版重新安排重心与字排 |

适合传播身份、创造力、工艺与空间感。教程、复杂功能说明、数据报告和客户案例仍需对应的内容证据。完整品牌片可将本风格作为主语言；软件功能片常用它组织引子、章节与收尾，再接可读的产品状态。

## 设计与运动规则

- **共享一份母形源。** 命名路径与构件，让矢量、三维前表面、平面遮罩和转场沿用同一轮廓身份。复杂字形按结构建立对应关系，不强套四顶点或固定部件数。
- **轮廓先成立。** 先看黑白剪影、负空间、字面比例和远距辨认，再设计材质。巨幅局部裁切可以制造张力，品牌和关键文案仍需完整可读的状态。
- **色彩有角色。** 分清环境、正面、侧面、强调与字幕。优先明亮环境与受控品牌色场；深色可服务文字或局部识别。相同色值在三维灯光和二维合成中不一定呈现相同颜色，以实际过渡帧校正。
- **运动有物性。** 实体构件通过旋转、位移和遮挡交接，平面路径承担展平、延伸和重排。字形不随载体无意拉伸；变形阶段可拆开，阅读阶段恢复清楚的字距和基线。
- **快慢服务注意力。** 近景揭示材质，退远揭示结构，平面段让文字可读，再以空间变化收束。密度、尺度、停顿都可变化，不把全部动作做成相同缓动。
- **转场带着对象走。** 提前定义承接的是轮廓、色面、边界还是负空间；检查中间帧的大小、朝向、遮挡与速度。仅把两个不同镜头交叉淡化不足以建立同一对象的连续变化。

## 制作流程与工具分工

### 1. 主张、母形和设计资产

写清一句品牌主张，设计能承担多次变化的字形、字标或符号。先完成若干关键状态：实体局部、展开、文字承载、空间构形、品牌落版；数量随叙事调整。

在 VectorCraft 建立可拆分路径、对象名和统一坐标；保留原生文档与 SVG。需要布局系统、多个尺寸或组件状态时使用 Figma；需要纹理、分层位图或材质图时使用 PhotoCraft。按资产需求选工具，不要求每个项目使用全部软件。本 AUREL 案例的矢量、三维与合成为 VectorCraft、Blender、EffectCraft，未据此声称 Figma / PhotoCraft 参与了本例制作。

### 2. 实体、摄影和连续预演

从同一轮廓建立实体厚度、倒角、合理法线和前侧面材质。用宽反射面与主次光向塑形，检查接触影、悬空关系及微距噪点。先做能够看清构形的低成本连续预演，再提高采样与输出质量。

相机应解释比例和结构。若只需要二维对象深度排列，可测试 EffectCraft 原生三维；涉及实体切面、反射、接触与复杂遮挡时，用 Blender 连续渲染，再合成字排。设计提案图只作为方向资料，不能把一张图的缩放称为连续三维动画。

### 3. 先解决三维与平面的连接

在确定的交接帧，从相同相机、分辨率和画幅导出**可见轮廓**，映射到合成坐标。平面路径的第一状态对齐该轮廓，再变到目标版式；载体与文字遮罩共用相同路径动画，文字本身保持所需比例。

本例曾把被地面遮住的腿部顶点也投影出来，造成交接残影。当前方法先按地面可见区域裁剪面，再投影；更复杂遮挡应使用真实可见面或渲染遮罩，不能沿用本例地面高度或假定每个字形都是四边形。检查交接前、交接时和交接后的密集连续帧，不能只看两张端点图。

路径形变需保持轮廓数量、点序、方向及控制点对应。必要时重采样或拆分多个形状；不要为了省步骤让笔画翻转、自交或负空间突然消失。

### 4. 原生字排、分层与最终画面

EffectCraft 保留路径、文字、字幕和关键帧，连续三维底片按需求使用透明 ProRes 等可保留 Alpha 的格式。核对直通/预乘边缘、颜色管理、阴影、前后景层级和极端角度的源画幅裁切。

本例设置图层 `startTime` 后会影响入出点：先设开始时间，再明确设定 `inPoint/outPoint`，并在实际渲染帧核对。不能仅凭时间线数值判断素材已正确接续。读取与修改属性仍以当前工具返回为准。

把声音占位与主动作一起预演。有配音时保留字幕安全区域，按每个真实镜头调整字色和边缘；字幕透明背景，句级时间来自最终语音。无需配音的短标识、循环或展厅片按用途制作。

### 5. 完整声音、审看和交付

采用下述音乐选择方法；有声项目按本次用户选择声音工具。完成声音后查看最终编码文件，保留旁白、配乐、音效、字幕、原生工程和相对资源路径。

画面未改而只替换配乐时，复制视频流重新封装即可；用编码画面哈希和原始语音 stem 核对保留范围。修改几何、相机、材质或光照后，先归档/失效旧帧缓存，再重渲染，避免跳过已有 PNG 导致新旧帧混用。

## 配乐搭配：按品牌与实际音色选择

| 目标气质 | 可试的声音方向 | 主要检查 |
|---|---|---|
| 安静、专注、强调材质的品牌 | 柔和钢琴、稀疏共鸣、缓慢低频与有呼吸的延音 | 是否过于忧伤或空泛；尾响是否遮住下一句；有无足够推动力 |
| 明快、灵活的创意工具或年轻品牌 | 圆润木质敲击、轻有机电子、简洁律动 | 是否变得过于可爱；连续快速音符是否抢走字排和旁白 |
| 有力度的发布会与品牌宣言 | 清楚但不过密的节奏、圆润低频、关键落点后的留白 | 冲击音是否盖过主体；是否全程用力；落版有没有音乐上的结束 |
| 明确的复古、游戏或像素主题 | 经过设计的芯片音色与复古合成器 | 是否是本次品牌有意选择；不能仅因属于“科技”便默认套用 |

钢琴不自动代表高级，电子乐也不自动适合科技。先写声音任务，再生成少量有区别的候选；将实际音轨放进同一段画面比较音色、密度、空间与情绪。用试听结果选择，不能按文件名、提示词中的乐器、BPM 或 `[instrumental]` 标签判断成功。

### 本次重配留下的经验

AUREL v2 旧曲的实际主导音色偏复古游戏感。响度、峰值合格仍无法解决用户指出的“音色和风格不搭”。v2.1 重新生成两条 MiniMax 候选：

- `minimax-aurel-v21-chamber.wav` 实际以柔和钢琴为主，选作本次主配乐。名称和请求不证明存在完整弦乐团，也不证明是真人录音。
- `minimax-aurel-v21-organic.wav` 实际呈现明快、近似木琴的木质敲击与持续铺底，保留作对照，适合更轻巧的创意品牌方向。
- 动作音从八处减到四处并减弱；保留 IndexTTS2 原两句语音和时间，在旁白期间对音乐做避让。新项目不固定这些数量或时间。

音色选择后再安排主动作与乐句。波形、谱通量可辅助找候选落点；阅读时间、语义重音和自然乐句优先，不要求每次移动机械对拍。保留片尾的最后一句、音乐收束与尾响空间；数字渐弱到零不等于音乐已经自然结束。

完整听审包括实际候选、最终配音版、最终纯音乐版及音画组合；核对多余人声、吞字、遮盖、剪口与尾部。模型辅助听审、技术测量、人工监听和用户意见分别记录。纯器乐标签不能保证没有哼唱，模型对具体乐器的判断也可能不准。方法见 [全长声音审查](listening-review.md)。

## 审看重点

1. 母形在三维、平面、负空间中仍可辨认；每次变化服务本次主张。
2. 三维到二维没有残影、跳尺度、错遮挡或露底；中间帧和连续片段都检查。
3. 实体有接触、厚度和光向，二维没有突然变成另一种色彩；裁切是有意构图。
4. 字形与文案有完整可读状态，字幕不抢主体、不同场景下对比合适。
5. 音乐与品牌性格相合，主动作有层次，旁白清楚，结尾听感完整。
6. 交付文件可解码，复制目录后原生工程可重开；新比例、循环及现场播放单独验证。

## 调用与案例

```bash
python3 scripts/choose_style.py --show sculptural-type
python3 scripts/plan_scene.py --scenario brand-manifesto \
  --style sculptural-type --title "本次品牌" --duration 20 \
  --out /absolute/new-project/plan
```

该入口生成规划，不自动生成新影片。也可在适用的软件发布、硬件材质、片头与循环场景中选择本风格；保留该场景原有内容要求，再制作专属资产。

案例位于 `assets/design-exploration/AUREL/`：16 秒 1080p30，配音字幕版、无字幕配音版、纯音乐版、明快器乐对照，VectorCraft / SVG、两份 Blender 工程与连续透明底片、EffectCraft 原生合成、字体、分轨、SRT 与审查记录。

复制案例到新目录后，在副本中执行：

```bash
python3 source/audio/mix.py
python3 source/build.py --preview --render
```

这是重建原案例；新品牌需重做设计、文案、路径和时间安排。只换音乐可在副本运行 `python3 source/remux_sound.py`，使用包内视频源；历史 v2 对比可通过 `--baseline /absolute/v2-delivery` 显式提供。字体和工具依赖见随包 `制作说明.md`。

历史事实：v2.1 画面及语音沿用 v2，四个主视频的编码画面与 v2 一致；三种有声主版本、无声画面及对照版均有完整解码记录，主配乐配音版与纯音乐版有全长模型辅助音画审查。现已按用户要求登记风格，原交付时的状态另存 `review/case-at-delivery.json`。没有把收录扩大为所有行业、画幅、专业人工监听或大厂旗舰质量验收。
