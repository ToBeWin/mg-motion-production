# 柔光工作台：设计与运动语言

以下为可迁移的设计与运动方法；按项目重新设计品牌、素材、内容、时间和声音。

## LW01 · 工作台到操作特写

- **资产：** 完整界面、目标控件、输入前后态
- **动作：** 建立全景 → 靠近目标 → 读/操作 → 返回结果
- **空间与连续性：** 同一工作台父级坐标
- **检查：** 目标控件不能在镜头接近时换位置

## LW02 · 持续任务与多格式成果

- **资产：** 持久输入/任务名、真实多格式成果
- **动作：** 任务保持 → 处理反馈 → 成果更替 → 下一步
- **空间与连续性：** 稳定任务对象与可换内容槽
- **检查：** 结果必须有不同且完整的设计内容

## LW03 · 利益点与成果并置

- **资产：** 短利益点、可读成果主窗口
- **动作：** 建立标题 → 成果进入 → 内部展示 → 标题收束
- **空间与连续性：** 不对称主次构图
- **检查：** 辅助文字不能重复抢走所有阅读注意力

## LW04 · 纵向成果舞台交替

- **资产：** 相邻成果、内容遮罩、持久外框
- **动作：** 旧内容向上退出 → 新内容从下承接 → 停稳
- **空间与连续性：** 共享方向和窗口尺度
- **检查：** 正文重叠时不可读，检查交接中间态

## LW05 · 来源与结果协同窗口

- **资产：** 职责不同的来源/对话与成果窗口
- **动作：** 主窗口建立 → 让位 → 第二窗口出现 → 关系可读
- **空间与连续性：** 横向协同与共享任务身份
- **检查：** 两张同样的卡片并排不能解释关系

## LW06 · 选区驱动局部编辑

- **资产：** 修改前、选区、工具条、指令、修改后
- **动作：** 定位 → 框选 → 指令 → 提交 → 局部改变 → 比较
- **空间与连续性：** 选区与内容共享局部坐标
- **检查：** 保留未要求修改的数值、名称和来源

## LW07 · 同一编辑语法跨产物

- **资产：** 不同类型的真实页面及编辑状态
- **动作：** 同一交互规则 → 换内容结构 → 展示新结果
- **空间与连续性：** 一致规则、不同布局
- **检查：** 不要把同一动画只换标题重复三次

## LW08 · 外部应用任务执行

- **资产：** 真实软件状态、操作位置、完成证据
- **动作：** 进入外部应用 → 执行 → 可核对变化
- **空间与连续性：** 产品界面与真实应用各自有边界
- **检查：** 动画示意不证明真实软件执行成功

## LW09 · 多能力概览

- **资产：** 不同大小和内容的模块、主张
- **动作：** 主张建立 → 模块按层级出现 → 稳定概览
- **空间与连续性：** 版式层级先于运动
- **检查：** 每格需承担不同信息功能

## LW10 · 倾斜界面与品牌收束

- **资产：** 完整产品界面、字标、结尾短句
- **动作：** 界面斜向经过 → 提炼主张 → 品牌停稳
- **空间与连续性：** 界面退为上下文，品牌成为焦点
- **检查：** 关键操作不放在最大倾斜的瞬间
