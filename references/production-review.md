# 制作深度与返修判断

| 层级 | 需要看到的成果 | 典型缺口 | 有效返修 |
|---|---|---|---|
| 主张与脚本 | 一句话价值与可展示的证据 | 词很大，却不知道产品做什么 | 用具体任务和结果重写，而非增加口号 |
| 视觉设计 | 有完成度的关键画面 | 字体/构图/材质像占位示意 | 修资产和层级，必要时重做方向 |
| 动态预演 | 连续镜头、主体归宿、信息阅读 | 镜镜淡入淡出、相机乱游 | 重设对象继承与转场语义 |
| 动画 | 有变化的速度、重量、停顿 | 全片一种 ease，所有元素同时动 | 分配主动作、次动作、稳定阅读 |
| 合成 | 阴影、深度、色彩、边缘和字形统一 | 胶片噪点掩盖粗糙素材，玻璃像塑料 | 修光照/材质/采样/颜色，减少无用装饰 |
| 声音 | 音乐结构、音效层次与关键画面呼应 | 鼓点平均，音效拥挤或落点错位 | 重编段落、留下空白、同步命名标记 |
| 交付 | 实际 MP4、可编辑源、重建方法 | 文件存在就算完成 | 完整解码，审看动作/阅读，实际听审 |

## 收到“离大厂质感很远”时

选一段用途相近的官方参考，比较同一层级：开头的主视觉、功能证明、连续转场或品牌落版。写下可见差距以及具体修改。不要把“使用 Blender / AE”“已 4K / 60fps”“技术检查通过”写成审美质量已提升的证明。

如果当前主要是形状练习，把它标为技术样例；不要直接加长到 30 秒。先用一段有完整价值链的短片验证新方向，然后才扩展。保留用户认可的审美方向，但允许重做薄弱的资产、字体与空间关系。

## 证据分层

- 源码与时间表：证明计划怎样执行，不能证明成片无异常。
- 稀疏抽帧：检查构图、字形与状态，不能证明运动流畅。
- 密集动作帧：检查变化先后和局部连贯，仍不能替代实时视听。
- 完整解码与响度：证明文件/信号质量，不等于音乐好听。
- 完整观看与听审：描述实际范围；未做就直说。
- 用户接受：由用户确认，不能由工具或内部评分替代。

检查量与片长和修改风险匹配，不为低影响文案修改增加整套形式化流程。旧版保留，新版明确编号和差异。
