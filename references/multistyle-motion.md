# 跨场景连续动效：不要把同一条片换三套皮肤

TRACE v10 得到用户“这次效果还可以”的反馈后，接续制作 SHIFT、ORBIT、一念协作 v11。认可只属于 TRACE v10；三条新片的完成、审看与待反馈范围分别记录。24 类用途目录和三领域九条既有风格路线数量不因此改变。

## 用主张决定运动

| 用途与观众需要 | 适合的动作逻辑 | 本次实例 | 不适合的替代 |
|---|---|---|---|
| 品牌广告需要记住一个动词与识别符号 | 字形的质量、切片、扩张、遮挡、重排；母形贯穿段落 | SHIFT：向前→打开→作品→创造，双斜杠最终归入标识 | 全片只有口号淡入，或把 UI 卡片改成品牌色 |
| 硬件功能发布需要看懂操作与反馈 | 实际部件运动驱动一个可见变量；材质镜头与图形相互解释 | ORBIT：转角→示意亮度→标尺→品牌 O | 静态产品上悬浮几个数值，或只有漂亮转台而没有功能主张 |
| 协作产品需要看到分工怎样产生结果 | 每个分支交付具体产物，再让同一产物连续进入结果 | 一念协作：文案/照片/色块/布局→ROAM 页面 | 三个空节点连线之后突然出现一个与前文无关的成品 |

这些是不同传播任务的解法，不要求每条都具备三维、任务流程、数据曲线或完整工作台。常规软件发布仍优先说明真实界面位置、动作与结果；品牌片不需要伪装成产品演示。

## 先完成最难的连接

选一处决定成片是否成立的变化，先做连续预演。例如：字形怎样穿过遮罩、旋钮与数值是否同源、照片移入页面时文字是否仍可读。风格帧漂亮但连接失效时，先改连接，不继续堆画面。

每个关键对象记录：进入状态、运动路线、遮挡层级、停止位置、下一状态、声音落点。可以用形变、匹配剪接、切片与剪辑，不必让所有物体一直可见；但不能在没遮住的地方提前换底图，造成“瞬间换页”的露馅。

### SHIFT：母形、字形、真正有效的遮挡

1. 选一个可记忆的母形。本例双斜杠先承接“向前”，再扩大成遮挡，片尾回收到品牌。
2. 中段以原生轮廓字体、主文字和前后比例形成深度；轮廓要弱于可读主词。不要把所有字都设为同样强的描边。
3. 几何波次转场先计算每个模块完全覆盖的区间。底图切换必须落在**所有模块共同全闭**的时间窗内。本例修订为 6.875–6.98 秒全闭，6.9 秒切换。
4. “作品”用原生文字遮罩承载运动纹样；“创造”用水平切片拆合。字幕保持稳定，避免主标题的变形同时影响配音阅读。
5. 逐字标识不能均分字符中心。按实际字宽布局，再加设计字距；特别检查 I 与宽字符的空隙。

原生路径、遮罩、合成与文字保留在 `effectcraft/brand.jsx`。短促剪接和可读停顿交替；连续不等于每一帧都匀速漂移。

### ORBIT：材质、运动和数据在同一时间上

1. 先建立有厚度、边缘和接触阴影的可用三维主体。透明底片使用与前景相容的明亮光场，避免给带黑底的材质图直接换白背景。
2. 三维姿态和原生反馈读取同一曲线。本例 `data/hardware-motion.json` 的 120 个样本同时驱动 Cycles 转角与原生 24→80 读数。映射为概念示意，不能写成硬件实测性能。
3. 数字使用可读的源文本关键帧，单独关闭数字层运动模糊，避免相邻数字叠成重影。几何元素可继续有合适的模糊。
4. 字幕、数字和产品都有净空。数字穿过曲线时，以**反向 Alpha 遮罩**让曲线退到文字后面；不要补一块与渐变背景不一致的“假白底”。
5. 弧线变标尺后保留结果阅读，再经上方空区回到品牌 O。线条的最短路径可能穿过产品；空间避让比一味追求短路径重要。

本例保留 Blender 源、透明底片和 EffectCraft 原生曲线/文字；重建默认复用底片，修改材质或相机才重渲。审看时同时检查部件、投影、数字、曲线和来源时间偏移。

### 一念协作：每个分支都要交付东西

1. 先准备一个内容完整的终点。ROAM 有可读标题、真实图片、按钮、主题栏目与配套 HTML，之后才反推三个分支。
2. 文案是后续页面的同一段文案；设计提供同一图片和配色；构建的外框变成页面表面。原生对象身份持续，比三个节点发光更有解释力。
3. 内容分批到达，给相邻对象错开时间或路径；布局框在后，照片与文字在前。连线的端点避开分支标签。
4. 当浅底深字跨入深色照片，用照片边界随动的轨道遮罩给同一文字叠加浅字版本。它改变字色，不替换文字，也不生成常驻字幕底板。
5. 收尾保留真实结果，同时给价值主张独立空间。检查概念页与交付 HTML 的主题文字、选中项、图像是否一致；MG 重排与浏览器像素录屏应分开说。

本例表达协作机制，未宣称在线 Agent 服务真的执行过。旧网站的历史检查记录也不能自动算作本次浏览器验收。

## 声音随动作改，不只随片长裁

三条分别使用本地 IndexTTS2 配音和此前已选定的 MiniMax Music 3 曲目。品牌片重拍节奏、硬件片保持克制、协作片留清楚的结果说明。复用音乐必须显式记录，不能说成本轮重新生成。

改了转场，就回到 `audio/<case>/edit-plan.json` 改声效落点。配音段的音乐压低采用进入/退出包络，片尾重剪成句尾而不是硬截。每个语句按实际音频长短设置字幕，原生边界落到整帧；重新测实际 MP4 的 AAC，而不是只看 WAV。

全长模型辅助审查用于发现读音、截断、遮蔽和音乐剪接问题；工具对乐器种类、逐帧同步或美术的判断可能不准，需与原生时间线及实际抽帧交叉核对。不能把模型的“制作质量高”抄成验收结论。

## 本轮实作与检查

`assets/multistyle-motion/` 保存三套原生工程、源码、音频、选定三维底片、Blender 源、配套 HTML、重建入口和检查记录。

```bash
python3 assets/multistyle-motion/rebuild.py --out /absolute/new-source --case brand --render
python3 assets/multistyle-motion/rebuild.py --out /absolute/new-source --case hardware --render
python3 assets/multistyle-motion/rebuild.py --out /absolute/new-source --case agent --render
```

每次使用不同的新目录；三条一起做可省略 `--case`。完整依赖、可选重混与 Cycles 重渲在随包 `制作说明.md`。

v11 为 3 条 / 52 秒，6 个导出；完整解码 3,120 帧，58 个带字幕主抽帧点、12 个无字幕抽帧点和 11 个转场的 176 个密集采样点；13 句原生字幕核对，最终媒体全长模型辅助声画审查，三工程新目录重建与六个选定原生帧一致性。具体哈希、返修和观察写在 `qa/`。这证明本轮检查完成的范围，不代表全片人工逐帧/耳机监听、用户已认可三条新片，或全部用途已经达到旗舰成片水准。
