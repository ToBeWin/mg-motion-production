# 先成立动态叙事，再判断成片质感

2026-10-28，用户对 v9 的反馈是“很多实际偏离了，没有达到 MG 视频的效果”。此前重配颜色、背景、材质与字幕解决了局部美术问题，但没有充分解决动作、转场和图形叙事。这个反馈优先于内部导出检查和自评，九条样片不能作为已经获得认可的 MG 发布片基准。

## 先选对传播形式

- **产品操作演示**重在操作与结果可信；可以长时间停在完整界面。
- **MG 产品发布**要求图形、排版、形态变化与剪接推动注意力和叙事；完整界面是必要时返回的定位点，不应成为每条片子的唯一画面。
- **产品摄影/材质片**用造型、灯光、材质和镜头展示物件；精美三维渲染本身不能证明 MG 转场和图形叙事已经完成。
- **动态海报/循环**可以保持稳定版式，只让一个元素运动；它是有效用途，但不能直接作为完整发布片的替代品。

这些形式可以组合，问题不在于二维或三维，也不在于节奏一定要快。先确认本片需要哪种体验，再确定样片能证明什么。

## v9 九条的实际定位

| 样例 | 已有内容 | 距离本项目 MG 目标的缺口 |
|---|---|---|
| TRACE 主片 | 任务、资料、答案与引用 | 接近界面演示；长段维持同一工作台，动作缺少层次与连续图形组织 |
| 软件编辑式 | 原文块、字阶与答案 | 编辑式排版研究；文字出现和换版不足以组成完整发布叙事 |
| 空间工作台 | 文档层级、轻微透视与相机 | 更像空间陈列；缺少文档自身状态变化与明确产物交接 |
| SHIFT 主片 | 母形转场、动态字体、字内纹样 | 已有较明确 MG 语言；继续审字形阅读、动作动机与节奏，不能仅靠强切片 |
| 克制品牌字排 | 字体、标点与留白 | 动态海报倾向；一个标点移动不足以证明完整品牌叙事 |
| 流动品牌 | 曲线形变与字标 | 曲线主要作装饰，未承担信息或品牌含义的转变 |
| ORBIT 主片 | 微距、金属与整机摄影 | 产品摄影路线；可作为 MG 素材与镜头，不等同于动态图形编排 |
| 光学短样 | 玻璃、滑杆与照明 | 材质与镜头研究；与功能、文字或图形的接力有限 |
| 结构短样 | 分件、拆装与标签 | 有结构动画，但信息标注与部件变化的配合仍可深化 |

此表依据本地源码、时间线与已审画面，是制作诊断，不是用户逐条评分。保留历史工程与用户曾认可的材质方向，调整其用途标签。

## 动作说明必须写在镜头表里

每个主要变化说明五件事：变化前的对象、引发变化的动作、变化后的对象、保持可识别的特征、观众获得的信息。比如“高亮原文带着编号进入答案，再由同一编号返回原文”，比“卡片漂浮、镜头推进、加光效”更具体。

按内容选择动作：形态变化、遮罩接力、路径描绘、字形编排、大小与构图匹配、空间调度、拆装、状态传播。不是每条片必须用全套，也不以关键帧数量或帧差作为质量分数。

安排主动作、跟随动作和阅读停留。主要变化需要清晰落点；次级内容可以错开进入。阅读期间停稳。持续漂浮、全片同一种 ease、所有元素同时运动，常会削弱重点。速度变化要服务对象性质和信息，而不是强行弹跳。

## 先做最难的连续段

高要求 MG 先完成一个有前后关系的短动态段，例如问题→检索→摘录→答案，再精修和扩展。关键画面与动态预演交替推进；不要先做大量精美静帧，最后统一加位移。用户已授权时直接制作，不能据此新增审批步骤。

制作中用正常速度的预演检查停顿、速度与声画关系；密集抽帧辅助检查遮挡、文字交叉和对象是否失去身份。静态构图好看、完整解码和音量达标，都不能代替这一层。

## TRACE v10 纠偏段

`assets/motion-correction/` 是 16 秒软件发布概念段，保留同一问题、两段真实示例原文、编号和焦点括号：

1. 输入框提交后收成问题条，三份资料从同一位置展开。
2. 两份相关原文高亮，带着编号分别沿上下路径进入答案；第一张资料的底板扩展为答案工作区。
3. 点击引用后对应资料展开，原文进入右侧资料；左侧答案保留副本。
4. 焦点括号与引用点收成品牌标记，完成同一图形语言的落版。

EffectCraft 原生形状尺寸、路径、文字、预合成、遮罩、图层顺序和关键帧负责制作。没有把截图缩放当作全部动画。示例仍是概念产品；没有在线模型检索或真实软件后端。

实际返修：摘录交叉时改为分离曲线路径；重复文字叠加时调整副本的出现时机；来源展开时让其底板正确遮住后方旧内容，同时保持资料标题与来源名称在正确层级；焦点括号先收向顶部再移到原文边缘，避免竖线扫过可读文字；只在有阅读需要时停留。最终动态质量以影片和用户反馈为准，本例不是已经验收的通用旗舰模板。

## 声音与验收边界

画面时间改变，配音、配乐和音效必须跟着重新剪辑。v10 复用已选 IndexTTS2 语音与 MiniMax Music 素材，重新安排五句话、音乐段落与事件声；没有用合成旋律替代配乐。原素材来源和编辑位置见 `audio/edit-plan.json`。

全长模型辅助审听、逐句转写、实际导出抽帧、原生对象检查、人工监听及客户审美接受分别记录。自动模型可能把稳定落版描述成淡出，要回到实际帧和工程交叉核对，不能把模型赞许当作验收。

最终 v10 辅助审查仍把画面概括为“固定版面加漂移配合信息转场”。本段仍偏 UI 卡片信息片，连续对象实现不等于发布片图形张力和品牌辨识度已经充分。记录这个未解决的审美差距，不只摘取声音评价或此前版本的正面描述。

后续用户对 v10 的直接反馈是“这次效果还可以”，随后要求其他场景与风格。将它记录为这一版本的方向认可，保留先前自评与辅助模型意见的时间范围，不把旧的未验收状态当作最新用户态度，也不把这次认可扩成所有场景已验收。
