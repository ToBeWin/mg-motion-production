# FOLD｜设计展开

风格 ID：`fold-design`。用户在看过《FOLD｜让灵感展开》后评价：“这个还可以，可以作为一种风格固化到skill里面”。本路线保留这次风格认可，供后续项目明确调用；它是已有完整案例的制作方法，不是只换品牌名便能自动完成的模板。

## 识别与选择

关键词：FOLD、让灵感展开、设计展开、创作工具发布、作品随操作变化。适合设计软件、创意 AI、内容平台，以及需要展示同一视觉如何扩展为多个输出的品牌片。先准备值得展示的作品，再让组件操作、对象变形与版式变化把制作过程讲清楚。

与 `software-ui` 的区别是：工作台负责建立操作位置，主要表现对象是画布上的作品；与 `kinetic-process` 的区别是：本路线突出作品和视觉系统如何变化，后者突出任务如何拆解、推进和交付。普通软件发布仍按产品内容选择路线，不能自动把所有产品改成设计工具。

## 保留的设计与运动语法

| 层次 | 可复用原则 | 在新项目中的做法 |
|---|---|---|
| 主体设计 | 有辨识度的原创母形、精确字排与正负形，结果本身足以作为设计作品 | 先设计至少一件完整结果及其必要变体；复杂度来自关系和细节，不来自装饰数量 |
| 环境与颜色 | 明亮纸感或柔和色场，主体与背景共享色彩角色，小面积强调色引导操作 | 分开定义环境、表面、正文、次级信息、强调色和字幕；用边缘、克制阴影与低强度纹理建立层级 |
| 组件 | 输入、选择、检查器与手柄都有前态、触发和后态 | 组件状态必须作用于同一件作品，避免只画漂亮控件或点击后切到不相关成图 |
| 对象连续 | 文字、形状、色块和选区在转场中保持身份 | 可让关键词进入画布、色块接替手柄、边界带动排版；每次接替都要有视觉依据，不要求复制这些动作 |
| 构图与版式 | 完整界面建立位置，特写展示变化，结果有完整阅读窗口 | 改尺寸时同步重排字阶、对齐、间距、裁切与元素显隐；不能只缩放一张扁平图片 |
| 转场与收尾 | 主体或其边界成为遮挡、版式桥梁和品牌形态 | 让当前动作带出下一状态；关闭遮挡后再换内容，片尾给标识与乐句完整落点 |

暖纸色、紫丁香与柑橘色是 FOLD 案例的配色，不是固定色板。八瓣几何、折叠字标、三个输出尺寸、32 秒和现有镜头顺序均可替换。保留的是设计质量、状态因果和连续变化；新片允许不同的母形、节奏、材质与叙事。

## 从资产到动画

1. **先完成作品。** 明确内容、字体许可、主次层级和输出尺寸。多尺寸分别排版，在关键画面中检验，而不是渲染结束后裁切。
2. **建立可编辑设计资产。** 按需要用 Figma 制作关键画面、变量和组件；用 VectorCraft 编辑母形与路径；用 PhotoCraft 处理少量分层环境、纹理和光影。工具按工作分配，不能为数量而使用。
3. **记录状态和交接。** 对关键动作写明 `前态 → 触发 → 变化 → 后态`，为同一对象保留稳定名称。路径、文字、背景和控件独立交给 EffectCraft，连续变形优先保留原生路径与文字层。
4. **先做最难的一段。** 对象身份变化、版式重排、遮挡闭合通常比片头更值得预演。随后安排完整界面、特写、结果停留与品牌收尾；时长取决于内容和阅读，不照抄案例。
5. **按动作配声音。** 有声版本使用用户选择的配音与配乐工具。配音以自然语义句组织，操作声少而明确，配乐重音围绕主要状态变化；字幕与片中色彩共同设计，保持透明背景并避让作品。
6. **在成片中检查。** 看正常速度、过渡中间帧、实际文字和片尾，同时保留无字幕版与原生工程。历史案例的技术检查不代替新片审看。

具体工具交接、字体实例、锚点返修与声音处理见 [设计驱动的软件发布片](designed-software-launch.md)，不在此重复引擎实现细节。

## 容易破坏质感的地方

- **组件只有装饰作用：** 追踪触发控件与变化对象，确保输入、主题与结果一致；概念交互不能标成真实运行的软件功能。
- **变形时文字跳位或被裁切：** 对齐方式改变时同步处理锚点与尺寸，检查中间帧；文字不要随容器非等比拉伸。
- **几何翻面或字标模糊：** 路径控制点顺序和切线保持连续，母版尺寸覆盖最大镜头尺度；实际验证连续栅格化。
- **全片漂浮或没有阅读停顿：** 相机只在揭示关系时移动，结果必须有稳定的可读窗口；操作、响应和落定不能永远同时发生。
- **背景抢主体、字幕变成按钮：** 用真实画面验证颜色与边缘层级，去掉无意义的强纹理和圆角字幕底板。
- **声音看似对齐但听感机械：** 依据实际发声定位字幕，不以字符长度估计；完整审听旁白尾音和音乐乐句。模型转写可辅助，不能用其粗略时间码判定精确同步。

## 调用与案例

自然语言：“用 FOLD／设计展开风格，做一支创意工具的发布片；展示作品从输入到主题变化，再到适配后的输出。”

```bash
python3 scripts/choose_style.py --show fold-design
python3 scripts/plan_scene.py --scenario software-launch --style fold-design \
  --title "本次创作工具发布" --duration 28 --out /absolute/new-project/plan
```

命令只生成制作规划。生成后把通用镜头描述改为本次作品的具体前后状态，再进行资产和动画制作；不把案例内容当作本次事实。28 秒只是命令示例。

可复用案例位于 `assets/design-exploration/FOLD/`：

- `case.json`：本次用户反馈、适用范围、交付和工程入口。
- `source/design/`：设计规范、Figma 构建与状态记录。
- `source/assets/`：原创几何、VectorCraft 路径与 PhotoCraft 分层资产。
- `source/FOLD.ecproj`、`source/build.py`：原生时间轴与重建入口；复制到新项目后再改写，保留归档原件。
- `source/audio/`、`editor-handoff/`：配音、配乐、字幕、分轨与剪辑交接。
- 三个最终有声 MP4 与 `review/`：32 秒案例和当时的实际检查。

原始检查早于本次反馈，按原样保留。用户认可的是这条风格可保留；并未逐项确认人工完整听审、所有变体或旗舰发布片质量。音乐尾部的模型意见存在分歧，具体记录见案例 `review/审查结论.md`。
