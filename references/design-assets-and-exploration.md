# 自由探索：让作品先于场景

用户在 2026-10-28 明确要求放开既有场景和样式，充分调度工具，自主探索；作品的应用由用户组合判断。这种委托以可见的创作成果为中心，无需追问产品名或把实验硬套成软件广告。

## 从一个可以持续变化的想法开始

选择一个有发展空间的命题，例如：线成为体积、折叠改变空间、字体变成结构、材质在同一形体上交换、微观运动汇成宏观秩序。它们是创作入口，不是新增的有限风格清单。

先做一次真正有变化的动作：前态、变化、后态、变化中值得看的细节。检查轮廓、重心、遮挡或颜色能否跨镜头保持关系。若只得到“若干漂亮静帧加平移”，回到动作本身；自由探索也需要运动上的发展。

可以做抽象艺术、图形舞蹈、字形实验、材质摄影、程序化生长或混合媒介。每个方向寻找自己的节奏与形态，不把卡片、球体、同心圆或任何当前案例当作默认母版。背景和画面不被场景目录限定，仍尊重当前用户明确的美术偏好。

## 设计资产不是收集装饰

按作品需求建立：

- **母形和轮廓**：路径、切线、正负形、重复规律、可变形拓扑。
- **字形和版式**：字体来源、准确字重、中西文关系、动态前后的排版。
- **光和材料**：厚度、边缘、粗糙度、反射环境、接触影、色彩角色。
- **可拆分结构**：独立路径、遮罩、层次、转轴、统一尺寸与坐标、透明边缘。
- **运动状态**：入场、主动作、停顿、变化、交接；持续的对象名称。

Figma 用于布局、可复用元素与关键画面；VectorCraft 用于矢量路径与造型；PhotoCraft 用于需要分层像素处理的环境、纹理和图像。不是每条片都要调用三者：实际画面需要哪种资产，就把对应工具用深，并记录作用。

## 并行设计，分层交接

关键画面与短动态预演互相修正。静帧看不出的遮挡、形变和阅读问题，在预演中解决；预演暴露素材不足时回到设计工具，而不是靠更多特效掩盖。

完整三维镜头需要真实连续姿态和相机，单张渲染平移只适合其实际用途。配乐可以先给出节拍骨架，关键音效跟随实际动作；旁白只在能增加表达时加入，提供便于再组合的无旁白音乐版。

## FORM / 形的发生（原创探索案例）

本轮从三条原创 Bézier 轮廓出发：Figma 关键画面 → VectorCraft 命名路径与原生高光 → PhotoCraft 分层环境 → Blender 带实体厚度的陶瓷、铜与玻璃曲面 → EffectCraft 原生路径描绘、光圈展开和字形编排。声音由本地 IndexTTS2 和 MiniMax Music 3 制作。

它展示一条实际工具链及探索方式，不代表同心轮廓是所有项目的推荐造型，也不是旗舰质量或用户验收的证明。完成及审查范围以案例交付记录为准。实际源工程位于 `assets/design-exploration/FORM/`；复制到新目录后按其制作说明操作，保护旧版。

## 本轮学到的可迁移事项

1. 不把 SVG 导入当成效果兼容保证。复杂阴影滤镜可能丢失，保留可编辑的设计原稿，在目标合成器重建光影。
2. PDF 分层导入可能仍是每层素材，并非可调控制点的 Shape。需要路径描绘或形变时，检查属性树；必要时用受限且明确校验的路径转换。
3. 文本保持可编辑与字形一致是两个问题。保留文字源；若跨引擎字形不一致，显式选同一字体或导出轮廓，不静默换字重。
4. 原生文件保存后重新打开、导出并比较；模板命令成功不能替代实际渲染检查。
5. 配方和工具可以沉淀，但新作品必须重新判断视觉方向与运动逻辑。
6. 字幕版、无字幕版与纯音乐版分别检查。预合成引用、音频编码或时长可能在不同交付链中出现差异；检查最终视频里的实际画面和 AAC，而非只检查源工程。
