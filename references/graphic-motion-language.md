# 图形组件：设计与运动语言

以下为可迁移的设计与运动方法；按项目重新设计品牌、素材、内容、时间和声音。

## GP01 · 中心对象接替

- **资产：** 轮廓不同但视觉重量相近的对象
- **动作：** 单一对象 → 形态/匹配切换 → 品牌几何
- **空间与连续性：** 共同中心锚点
- **检查：** 不必把无法连续变形的轮廓强行插值

## GP02 · 道具群与品牌角色

- **资产：** 前景品牌块、中景工具、中心自有角色
- **动作：** 品牌块扩张 → 道具展开 → 角色接近 → 回到稀疏
- **空间与连续性：** 前中后三层与尺度反差
- **检查：** 对象有语义和统一造型，不是随机粒子

## GP03 · 能力词沿轴轮换

- **资产：** 共享文字、并列能力词、对应图标
- **动作：** 第一词稳定 → 沿弧线退出 → 下一词进入阅读槽
- **空间与连续性：** 稳定轴心和共同阅读基线
- **检查：** 快切后仍能读清每个能力

## GP04 · 关键词成为控件

- **资产：** 句中关键词、箭头、菜单、选中态
- **动作：** 短句成立 → 关键词可操作 → 菜单展开 → 选择反馈
- **空间与连续性：** 文字身份延续到 UI 控件
- **检查：** 只弹菜单但不改变状态不构成操作

## GP05 · 动态字排尺度冲击

- **资产：** 短语、手写强调词、放射线
- **动作：** 小尺度短停 → 关键字放大 → 一次强调 → 收束
- **空间与连续性：** 尺度与密度反差
- **检查：** 不是每句都大幅回弹或爆炸

## GP06 · 权限列表纵深运行

- **资产：** 独立行平面、勾选状态、父级空间
- **动作：** 面板展开 → 列表进入纵深 → 状态逐项传播
- **空间与连续性：** 行平面沿深度排布，焦点可读
- **检查：** 虚化和透视不能让整列都不可读

## GP07 · 镜头跟随输入句

- **资产：** 完整输入句、强调词、输入框与提交按钮
- **动作：** 框转正 → 贴近文字 → 沿读序移动 → 回整句 → 提交
- **空间与连续性：** 内容读序驱动镜头
- **检查：** 不把长提示词当模糊纹理

## GP08 · 文件链接到页面纵深

- **资产：** 生成状态、文件链接、多页结果
- **动作：** 生成 → 链接 → 点击打开 → 正视阅读 → 多页展开
- **空间与连续性：** 同一结果的从入口到内容深度
- **检查：** 后页必须有不同的真实设计内容

## GP09 · 结果收成可复用方法

- **资产：** 任务成果、方法标签、成员身份
- **动作：** 产物收拢 → 保存方法 → 成员进入 → 复用价值
- **空间与连续性：** 对象身份与主张连续
- **检查：** 头像出现不等于发生协作

## GP10 · 协作范围与品牌收束

- **资产：** 消息、文件、地理/平台符号、自有品牌
- **动作：** 协作内容接续 → 范围扩展 → 主张与品牌停稳
- **空间与连续性：** 章节尺度与媒介变化
- **检查：** 地球/平台/光束要服务已证实的能力或品牌目的
