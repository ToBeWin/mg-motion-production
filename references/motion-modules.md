# 从动作目的选择方法

这些是可组合的制作方法，不是 18 个都已封装完毕的插件。先写动作前后的状态、观众应理解的差异、被继承的对象，再选实现。复杂资产、绑定、跟踪与模拟按本次项目验证。

| 方法 | 适用与连续关系 | 实现起点 / 常见失误 |
|---|---|---|
| 01 按语义揭示文字 | 宣言、标题、信息分层；短语完整出现后留阅读 | 文本层与局部预合成遮罩；避免字符裁切、全句一直跳动 |
| 02 焦点与选区迁移 | 操作演示、教程；观众始终知道当前步骤 | `focus` 组件；高亮移动与实际操作一致，不同时突出所有区域 |
| 03 沿路径描线 | 流程、地图、结构线；端点与路径同步 | `route` 组件；同一坐标与弧长时钟，地图另保留投影 |
| 04 对象交接 | Agent、服务流程；同一任务跨责任或阶段 | `handoff` 组件；名称、来源、完成状态连续，展示交付物 |
| 05 遮罩 / 轨道遮罩揭示 | 章节、产品显现；遮挡物有明确前后关系 | 原生 mask / matte / 贴合字框预合成；检查中间帧 |
| 06 图形语义变形 | 图标、科普、品牌母形；轮廓改变对应含义变化 | 对应顶点或分阶段替换；拓扑差异大时不强行乱扭 |
| 07 构图匹配转场 | 产品到界面、微距到整体；继承位置、轮廓或动作 | 先配准关键对象再切；转场不掩盖证据缺失 |
| 08 持续主体与相机揭示 | 空间 UI、产品、结构说明；镜头运动揭示关系 | 相机目标、视差、遮挡；阅读阶段稳定，不为动而转圈 |
| 09 系统重复 / 阵列传播 | 品牌系统、批量能力、网络规模 | repeater 与统一控制器；重复元素应有共同变量，不虚构数量意义 |
| 10 数据生长与同尺度比较 | 业绩、研究、成本差异；标尺保持可见 | `compare` 的数值/宽度共享进度；不能用不同轴制造差距 |
| 11 排序 / 筛选 / 表图变换 | 数据故事、产品分析；对象有稳定 ID | 数据驱动位置，保留来源与单位；变换过程不偷偷改值 |
| 12 爆炸拆解与回装 | 工业、硬件；层级与装配关系可理解 | 正确模型、局部轴与有序位移；先做碰撞和遮挡预演 |
| 13 剖面与机制流 | 科普、材料、设备原理；外壳和内部有对应关系 | 真实截面或明确示意、路径粒子；不把装饰粒子当机制 |
| 14 光学 / 金属微距 | 材质、工艺、品牌质感；反射随几何与灯光连续 | 已有 Form/ORBIT 源码；先修实体、法线和灯光，再调合成 |
| 15 跟踪标注与遮挡 | 实拍增强；标注依附同一现实对象 | 测跟踪点、镜头畸变、遮挡 matte；平移贴字不是世界空间跟踪 |
| 16 角色预备 / 动作 / 反应 | 教学、故事、服务；意图可从姿态读懂 | 角色分层、绑定与关键姿态；需要专门资产与预演，非现成角色引擎 |
| 17 状态反馈与弹性响应 | 确认、加载、错误、完成；终态明确且可中断 | 状态机、取消/重入/减弱动态；弹性有阻尼，不让每个元素都弹 |
| 18 循环与节拍交接 | 网站、展厅、开场；接缝速度与对象状态闭合 | 循环源已提供；`countdown` 处理一次计时与结束，不能自动当无缝循环 |

## 组合规则

一次关键变化只保留一个注意力中心。主体动、相机动、字排动可以错开，不要每个层级同时抢焦点。主动作前可有预备，关键结果后必须有停顿；停顿长度由阅读和理解决定。声音标记放在实际动作或结果确认点，画面改时同步编译 cue。

例：API 发布采用文字揭示 → 请求对象交接 → 返回结构展开 → 可读结果停顿。工业片采用整体识别 → 有序拆解 → 剖面说明 → 回装。展厅循环采用独立信息单元 → 自然接续 → 对象与镜头回位。三者不能只替换同一条几何片的标题。
