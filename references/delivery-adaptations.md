# 按观看条件适配交付

规划器记录画幅与静音要求，不会自动重排图层、重渲染或生成交互文件。确认本次实际交付环境；固定渠道的规格须在制作时核对，下面不是某个平台的永久参数。

| 载体 | 设计动作 | 检查与输出 |
|---|---|---|
| 16:9 发布 / 演讲 | 以大屏阅读距离安排文字，展示具体结果 | MP4 与可编辑工程；现场若另有帧率、音量、倒计时要求，使用实测规格 |
| 9:16 社媒 | 并排证据改为上下或分步交接，字号重新设计 | 按目标平台 UI 遮挡区核对；静音也能理解，检查 CTA 驻留 |
| 1:1 / 4:5 信息流 | 收紧横向动作，重排长标题与数据图例 | 不是横片中心裁切；从第一帧到结尾完整检查 |
| 特殊 LED / 多屏 | 按真实像素、屏缝、站位和播放端布局 | `--size` 只记录像素；需要正确映射和现场播放检查，不能仅凭电脑预览验收 |
| 展厅 / 导览循环 | 任意时刻进入都能识别主题，信息单元可独立理解 | 优先可读性，检查接缝、长时间播放和声音环境；不强迫从第 0 秒看 |
| 网站循环 | 背景视觉给前景内容留空间，运动少而有义 | 无声音依赖、首帧 poster、循环接缝与实际页面性能；按页面需要提供减弱动态方案 |
| 透明栏目 / 实拍叠加 | 前景与背景对比、字段长度、遮挡关系 | 与目标软件匹配 alpha 格式及预乘方式；在明暗两种底色实际叠加验证，不把普通 H.264 称作透明视频 |
| 界面运行时 | 定义等待/成功/失败/取消/重入与减弱动态 | Rive / Lottie / 前端动画需目标运行时验证；仅交 MP4 时明确为动效示意 |
| 本地化 / 字幕版 | 替换字体并重新测字宽，改变阅读预算 | 检查缺字、长文溢出、字幕与主画面竞争，保留原文与译文对应关系 |
| 有声 / 静音版 | 有声版用命名动作标记混音；静音版补足必要视觉信息 | 声音测量与实时听审分别记录；静音不是删掉音轨便一定合格 |

实际请求只需要一条片时交一条片，不默认批量生成全部比例。复用资产时保留独立构图、时间线与版本号。数字、产品功能、客户结果和来源随版本一起保存。
