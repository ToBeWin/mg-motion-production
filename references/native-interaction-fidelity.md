# 软件 MG 的原生交互与注意力引导

除交互外，同时读 [整片 MG 动作方法](native-motion-vocabulary.md)，包含字排、形态、空间、阵列与品牌收束。

这是一套跨风格制作方法，组合 `evidence-led-showcase`、`graphic-product-pop`、`luminous-workspace`、`companion-ui-explainer` 使用，不增加风格数量。

2026-10-31 用户指出：几条软件影片共同缺少可见点击，交互不够细腻、真实，也没有充分发挥 AE 平替的能力；随后要求增强、增加 MG 引导。本轮保留旧片，增加四路线的原生交互精修及一条成果迁移验证。新文件的位置与检查范围在 `assets/native-interaction/case.json`；不得把旧样片的认可沿用到本轮。

## 核心：每个动作都有依据与后果

先在真实产品核对一条完整链：可见入口 → 到位 → 操作 → 界面响应 → 同名成果 → 继续阅读或使用。把前态、控件、后态和结果对应起来，再设计动画。没有真实响应的光圈，只能说明“这里被强调”，不能证明产品完成了操作。

不要求每条宣传片变成教程。一至两条完整操作链建立可信度；其余章节可以继续使用字排、成果展开、空间交接和品牌 MG。

## 输入框、鼠标和声音要成为同一条动作链

输入有叙事作用时，先表现真实输入框的空态、聚焦、文字与插入光标、可提交状态，再连接到已有任务及成果。使用真实控件和原文，输入框的字号、行距、圆角、模型/专家选择等保持来源一致。长请求可节选，但标明节选，不修改影响结果的约束。

本次追加 `input_library.jsx`：实采空白与已输入状态，原文字形像素由原生遮罩逐段揭示；插入光标跟随同一字形边界，完整句子停稳后才提交接力。点击输入位置和发送位置都以尖端为热点；发送按钮采用真实启用状态，避免单独裁出方形光晕或凭空画一个控件。输入框的真实圆角需要透明裁切，不能留下原工作台的矩形背景边缘。输入结束通过独立白色形态连接工作台，文字不做非等比拉伸。

这次草稿只用于素材采集，采集后清空，没有发送新推理。提交动作和打字时间是已完成任务的编辑回放；不能称为连续录屏、逐键实录或产品响应速度。中文输入工具若丢字，使用粘贴并核对实际可见内容，不用缺字截图继续制作。

声音读取同一 `focus / type_start / type_end / submit / click` 时间点。键入声宜轻且稀疏，提交与附件打开用短触感声，窗口/页面运动另用轻转场声。配音说明此刻的意图、结果或价值，不逐个念按钮；纯 MG 展开保留音乐空间。旁白活动段给音乐避让，测最终编码文件而非仅测分轨。句级字幕随所用语音片段移动，裁取已有配音时在停顿处剪切，不能重叠两段旁白。

## 采集与坐标合同

记录 `source screenshot / crop / hotspot / hit rectangle / action / after state / file identity / response evidence`。原始采集与使用版分开，排除账号和个人明细。真实任务已经完成时，可打开已有成果，不为镜头重复发起付费任务。

局部截图的热点必须按同一变换映射：`viewport_origin + (source_hotspot - crop_origin) × uniform_scale`。指针、点击、焦点框和后态预合成放在同一父级或视窗中；不能界面在缩放，鼠标还按屏幕绝对坐标飞行。

## 可编辑原生组件

| 组件 | EffectCraft 实现 | 检查重点 |
|---|---|---|
| 指针到位与按下 | 热点为锚点的矢量路径；曲线运动；短暂停留；按下/释放缩放 | 尖端落在实际控件内，不以箭头中心对齐 |
| 点击反馈 | 小范围描边环与光标按压；不改变截图里的控件事实 | 反馈在实际触发时刻，不全屏爆光 |
| 操作指向 | 可修剪路径、短动作词、文件行描边 | 线头对应目标，文字不盖住控件 |
| 文件到预览 | 原生形状遮罩由当前文件区域展开；同名真实文件响应 | 先点击再出现内容，前后身份一致 |
| 长页面阅读 | 固定视窗与工具栏；内容在独立预合成中滚动 | 不让整个浏览器随正文滑走，不凭空补写文本 |
| 局部放大 | 同一源图的裁切预合成；保留名称、数值与比较口径；原生位置/尺度/阴影 | 放大的是原像素，不新绘一个更好看的虚假指标 |
| 阅读接力 | 指向线、区间括框、标题下划线、必要时背景退让 | 一次只强调一个语义，阅读完成再接下一项 |
| 文件展开与归位 | 独立页面、父级、浅阴影、错峰角度和位置 | 先正视阅读，再分层；不恢复被否定的玩具模型 |
| 分步导览 | 持续步骤轨、状态节点、当前说明 | 是片内导览，不冒充产品执行日志或成功状态 |
| 声音联动 | 从同一 `click` 标记生成按压声，转场声单独标记 | 点击音、光标按压与响应逐帧核对 |

本例以 30 fps 制作，指针到位后约 220 ms 停留、约 120 ms 后接入响应，是本次剪辑选择，不是测得的产品延迟。需要表达实际耗时时保留运行记录，不用编辑时长代替性能。

## 四条风格各自怎么用

- **实证式发布**：操作打开结果，结果让位给摘要；正文滚动、局部放大后再进入多成果巡览。保留案例、依据和矩阵之间的完整关系。
- **图形组件产品发布**：真实文件行是主动作对象，描边与遮罩接到真实结果；后方页面错峰展开，配合较大的价值字排。不能只靠给窗口加倾斜来制造动效。
- **柔光工作台**：任务锚点持续存在，主窗口移动让出关系空间；视窗和工具栏稳定，正文、放大镜与阅读线在内部接力。柔光不替代实际操作。
- **角色/指针导览**：指针先定位，步骤轨解释找到、打开、阅读；重点区域随后被引导。品牌不需要卡通时用持续指针和步骤叙事，不能擅自加入吉祥物。

适当增加动作句式，不在每个镜头重复全部组件。先解决“此刻该看哪里”，再决定用描边、连线、放大、遮罩还是镜头。一个镜头同时出现游走鼠标、闪烁框、放大镜、全屏扫光和弹跳字，通常会妨碍理解。

## 制作与交付

1. 核对真实入口、后态和文件，写坐标与时间合同。
2. 设计普通态、聚焦态、响应态和阅读态；动作词、线宽与字幕采用统一色彩角色。
3. 先渲染最难的点击、遮罩中段和滚动接力，检查热点与源内容。
4. 以 EffectCraft 的形状、路径修剪、遮罩、预合成、关键帧、阴影和必要的运动模糊完成主画面。文本阅读时停止运动，不能用模糊遮错。
5. 音效读取相同触发时间。既有授权且合格的声源可以按原身份复用，重做剪辑、避让与字幕；不因此声称重新生成或完成了新一轮听审。
6. 输出有字幕、无字幕及音乐版；保存原生工程、分轨、字幕、素材出处与验证记录。复制目录后重开渲染，确认媒体和焦点位置。

共享原生源码及验证器在 `assets/native-interaction/`。它是可配置的交互组件和本次模板，仍需提供有授权的产品素材与内容，不是一键把任意截图变为商业成片。客户实采图片、报告与音轨不随通用 Skill 分发。

## 逐帧与实际播放检查

- 点击前、按下、释放、响应开始、遮罩中段、落稳、滚动中段、放大镜进入/退出均检查，不能只看首尾静帧。
- 缩放后控件仍命中；指针不遮标题、数字或结果；引导线不指错一行。
- 源图裁切、正文滚动和工具栏没有分离错位；真实文档的原始口径仍可见。
- 放大镜进出不产生重复数据暗示；先给出原位置，再解释局部，不制造新的增长或成功状态。
- 全片解码、音峰/响度、素材完整性、视觉审看、主观听审、用户认可分别记录。此次精修不代表历史所有 90 秒影片均已重新导出，也不代表旗舰审美已经通过。
