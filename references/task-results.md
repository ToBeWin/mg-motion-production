# 任务到结果：Agent 与数据片的两种证据链

适用入口：`agent-workflow` 和 `data-story`。完整案例在 `assets/task-results/`。一念协作 v3 为 27 秒深色界面片；DataTalk v3 为 26 秒纸色与钴蓝数据片。它们保留各自风格，分别设计结果与动作，不能仅改标题当作所有业务的通用模板。

## 先做实际结果，再拍它如何产生

Agent 的交付不应停在“完成”卡片。先做一个有内容、可浏览的结果，再决定哪些过程值得展示。此例先完成 ROAM 三主题旅行灵感页，检查主题切换、导航目标和 390 px 手机宽度，最后把这些证据放进动画。

完整链条：明确简报 → 三项需求 → 页面结构与设计 → 三项可核验检查 → 网页近景 → 一次可见交互 → 网页、素材和检查记录。研究、设计、检查各有产物，连线只连接实际交接。视频中的 Agent 工作过程仍是概念表达；配套网页的真实存在不能证明自动 Agent 服务已经实现。

照片属于结果资产。此例的原创海岸影像改善内容与视觉层次，但所有标题、按钮、主题选项和状态仍是原生可编辑图层，不把整个页面烘焙为图片。素材来源记录在 `assets/provenance.md`。

## 输入和输出保持同一个对象

一念协作的简报面板在 3.2–4.4 秒收缩为任务栏，任务文字保留；同一 ROAM 网页从设计位进入检查位、近景和结尾，没有在相邻镜头换成无关图样。18.2 秒点击“山野徒步”，网页与手机读取同一个 `Task state / Route`，主题和结果文字同步切换。

界面内容按 2 倍内部尺寸制作。角色全景负责说明关系，结果特写负责阅读与审美，结尾给出文件。不要在每个时段同时要求观众阅读所有微小文字；应有明确主次和足够停留。

这套方法可以迁移到代码生成、文档助手、研究任务、设计协作或多工具编排，但每个任务必须换成自己的可检查产物。没有浏览器记录就不能写“链接全部可用”；没有测试就不能写“测试通过”。

## 数据片先固定口径，再转换视觉编码

DataTalk 用同一份 CSV 生成计算结果、原生图形和可下载 HTML 简报。指标为访问次数，比较两个连续且等长的 28 天窗口。总量 10,000 → 12,000，增长 20%；自然搜索增量 1,300，总增量 2,000，贡献 65%。65% 不是本期访问占比，也不说明因果、营收或转化效果。

八个数值单元格变为两条总量堆叠条，使用相同起点与比例；随后只保留本期对应的四个对象，尺寸改为增量，再合并为 100% 增量贡献图。每次编码转换都更换标题与单位，退场旧标签。总量条和增量条使用不同尺度，不能让观众误认为它们在同一比较阶段。

邮件增量为 0，宽度必须实际为 0；通过基线与“+0”文字呈现，不能为了可见性画一条假值柱。此案例限定四渠道、非负增量和正总增长，`analyze.py` 在不满足案例条件时拒绝生成。负贡献需要发散编码；零基期或零总增量必须重新定义指标，不能除以零或继续画 100% 堆叠。

## 从结论到有边界的下一步

65% 蓝色段延展为下一步行动卡的标题区，再交付完整报告。行动为“复盘自然搜索落地页，并验证转化质量”。当前数据没有转化率，画面明确说明需要补充转化数据，不能把待验证动作写成已经证明的业务成果。

此方法可用于经营复盘、研究结果、产品分析和监控解释。金融、医疗等专业内容还需要任务对应的来源与审查；当前虚构访问数据样例没有验证这些领域。

## 原生曲线的一个实际陷阱

本轮 EffectCraft 0.16 的位置属性为 `ThreeD_SPATIAL`。相邻关键帧即使数值相同，自动空间贝塞尔切线仍造成停留段漂移：总量条偏离同一基线，100% 堆叠段出现缝隙。仅看关键帧值发现不了这个错误。

`studio_helpers.jsx` 在 `U.key` 中对需要直线路径的空间属性关闭自动/连续切线，并显式将空间入、出切线设为零；时间贝塞尔缓动保留。随后用 MCP 的 `valueAtTime` 核对停留段实际位置，再看导出帧。不要把空间路径和时间缓动当成同一设置；真正需要弧线的镜头应另行设计切线，而不是全局使用这个约束。

至少检查每次变换的开始、中点、结束和阅读停留。图表还要计算：共同起点、比例、宽度总和、零值、标签是否属于当前编码。数值正确但画面错位同样不合格。

## 音画由共同的动作时点驱动

两片分别编写原创 96 BPM 与 108 BPM 音乐，使用不同的和声与乐器组合。点击、检查确认、图形移动和报告出现的 cue 读取 `production-plan.json`。视觉关键点击也读取同一文件，避免画面修订后音效继续使用旧时间。

一念协作突出任务提交、逐项检查、浏览主题与完整交付；DataTalk 用更轻的钢琴、低音和马林巴留出阅读空间，强调分析、占比确认和报告生成。动作前适度降低音乐电平，收尾单独写终止与淡出，不直接截断长音轨。

`notes.json`、`cues.json` 和音乐/动作音分轨均随工程交付。macOS 内置音源在宿主机，不随包分发。技术检查记录最终 AAC 的 LUFS 和 true peak；这些数值不能证明音乐好听或音画主观配合已经验收。

- [OpenAI Codex app](https://openai.com/index/introducing-the-codex-app/)：参考具体任务、关键操作和结果之间的层级，减少无结果的节点表演。
- [Google Gemini 3](https://blog.google/products-and-platforms/products/gemini/gemini-3/)：参考混合内容在连续空间中保持身份的方式；本例不借用其品牌、音轨或镜头素材。

2026-10-26 重新核对官方页面，并查看此前存档的 Claude Design、Codex 与 Gemini 视频抽帧。这里的观察支持画面与状态顺序，不声称对参考片完成全片听审、精确曲线反推或确认原作者使用 AE，也不把这些案例称为最新发布。

## 复用与检查

```bash
python3 assets/task-results/rebuild.py --out /absolute/new-project/source --render
python3 assets/task-results/rebuild.py --out /absolute/audio-project/source --regenerate-audio --render
```

打开相对路径工程后，在新目录实际重建并至少重渲一帧，确认素材可移交。检查配套网页的实际交互和报告下载；这些与视频 MP4 的完整解码、转场抽帧、状态和音轨测量分别记录。用户是否认可、是否完成实时听审，必须与技术通过分开。
