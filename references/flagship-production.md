# 三条标杆方向的制作与返修

本轮目标是提高三个重点方向，成片仍是原创概念案例。学习了本地已有官方 Apple、Google 与 Meta 参考片的画面材料；观察范围是抽帧中的空间、构图和变化，未将其当作本轮最新发布调查、精确速度测量或制作软件证据。

## TRACE v2：正常软件发布优先

28 秒，保持完整应用工作台。侧栏、资料、问题和答案有稳定位置；光标发送问题，定位两段原文，摘录进入答案，点击编号打开对应来源，最后回到产品价值。

三个关键要求：

- **操作成立。** 输入内容与来源、答案相符；不要用虚构数字或没有内容的窗口替代功能证明。示例文档、问题、引用和可下载答案共用 `data/validated.json`。
- **结果保留。** 打开来源不能让回答凭空消失；本轮返修在摘录移动到右侧原文时保留左侧回答与引用编号。阅读镜头停止相机运动。
- **概念边界明确。** 配套本地原型可按文件、同步、权限关键词返回对应示例资料，能回看来源并下载答案 JSON；没有在线模型或真实产品后端。逻辑检查与浏览器交互验收分别记录。

前期的编辑式 TRACE 另存为风格研究，没有将它当作正常产品 UI 片的替代。软件空间研究用相同的工作台与来源平面，便于比较内容相同而空间表达不同的效果。

## ORBIT v4：把材料放进摄影关系

20 秒、五个镜头：加工切边微距、光学表面与转动、侧面轮廓、整机功能、品牌收尾。Blender Cycles 制作材料和摄影底片，EffectCraft 制作文字、原生合成与字幕。

灯光不是越亮越高级。早期材质过白，切边、玻璃厚度与金属反射混在一起；返修降低环境与曝光，增加不被相机直接看见的负补光反射卡，调整粗糙度。浅色环境保持，但主体出现明确暗反射与亮边。负补光卡与黑色背景是不同事情。

保留真实几何：旋钮切纹、倒角、光学盖厚度、底座接触、内嵌刻度。相机围绕有观察价值的部位变化，不用漫无目的转圈。切换镜头时记录切前/切后姿态，避免贝塞尔曲线穿越另一镜头造成飞行与运动模糊拖影。本轮最终抽帧发现：即使只在相邻一帧硬切，快门采样仍会跨到另一位置；已在四个切点前后的 8 帧关闭运动模糊并重渲染，本机该布尔属性不可动画化，使用逐帧渲染脚本设置，并在场景自定义属性中保留切点清单。不要声称引擎支持未验证的布尔关键帧。

当前是原创设计概念，结构研究是展示性装配模型，不是制造级 CAD、性能测试或真实硬件发布。使用 16-bit 合成也不能把 8-bit PNG 摄影底片说成 HDR。

## SHIFT v2：用同一个形状组织转场

20 秒。斜切母形先揭示动词，再携带色场、打开缝隙、进入原生三维字体空间，变为字内重复纹样，最后形成品牌标识。中文大字有完整阅读停顿；动态字体、剪切与重复器承担明确动作。

返修发现：三维字体过小、跨色场时出现空白、片尾蓝场早于标识到达。调整前景字尺度、后排轮廓字、相机距离、母形切入顺序和结束时点。不能靠提高导出分辨率修复这些叙事与构图缺口。

品牌的另外两条研究采用克制衬线字排、连续色带形变，各自的空间、速度与音乐重新安排。它们不用 SHIFT 主片的大字节拍作为统一模板。

## 原生工程的实际注意事项

- EffectCraft 的导入素材或嵌套合成改 `startTime` 后，显式重设 `inPoint` / `outPoint`。本轮发现负偏移导致空间工作台漏显、光学素材提前结束；不能只看第一帧确认素材有效。
- 交付图层与高清预合成的坐标倍率分开处理。`U.add` 调整源倍率，不代表所有底层 transform helper 都自动换算。
- 先抽查首帧、主体进入、阅读帧、转场两侧、片尾，再检查最终 MP4。原生单帧正确不保证整条导出时间范围正确。
- 本机 GPU 在受限环境中可能不可用。只有已授权的渲染使用主机 GPU 权限；保留错误日志，勿因 CPU 草稿成功便宣称 Metal 渲染成功。
- 资产相对路径、复制到新目录的重建、配套字体与引擎版本都影响可编辑交付。不要只打包最终 MP4。

最终检查证据放在 `assets/flagship-studies/qa/`。九条路线的可执行程度、自动检查、抽帧审看、真实听审及用户认可分开报告。

## v8 声音复核

九条样片已完成全长模型辅助声画听审与返修，29 句旁白在实际返回中核对，字幕边界另以信号、原生时间线和最终 MP4 抽帧检查。具体方法见 [全长声音审查](listening-review.md)，逐片修改、候选淘汰和限制见 `assets/flagship-studies/qa/previous-v8/listening-review.json`。这是模型辅助审查，人工监听与客户认可仍未完成。旧版保留，不能把使用音频模型等同于人耳验收或大厂旗舰品质证明。

## v9 颜色、空间与字幕返修

用户否定了统一近黑字幕，也指出背景、主体与颜色缺少协调。将环境色、主体、强调色、次级信息和字幕分别定义；软件使用瓷白光场和蓝紫引用，品牌保留钴蓝动词、暖纸陶土、连续蓝色曲线三个方向，硬件保持浅色摄影环境与银色材质反射。九条都按画面选字幕色，不用统一的黑字加白边。

空间工作台重新排列两份资料与主界面，调整阅读距离与相机以避免边缘挤压。流动品牌把穿过字标的多色带改为两条同色系矢量曲线，中央留白。结构展示重做 Cycles 灯光与材质，透明底片保留接触影；过亮、发白的初稿未采用。SHIFT 删掉三处与旁白重复的小字，保留主标题和字幕。

实施和验收细则见 [色彩、环境与字幕](color-environment-captions.md)。本轮 12 个最终文件完整解码，9 条关键帧及字幕区域审看，29 处字幕原生属性和句级边界核对。音频包与 v8 相同，本轮没有重复宣称全长听审。具体范围见 `assets/flagship-studies/qa/visual-review-v9.json` 和 `render-provenance.json`。
