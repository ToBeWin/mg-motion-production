# 角色与指针导览：连续动作与迁移

以下为可迁移的设计与运动方法；按项目重新设计品牌、素材、内容、时间和声音。

## CU01 · 遮挡后探出与招手

- **资产：** 参见组件蓝图 UI02,UI03,UI13
- **动作：** 输入框前景遮住下缘 → 主体出现 → 小手招呼 → 停稳
- **空间与连续性：** 前景遮挡与身体局部坐标
- **检查：** 先出现再表演，不靠整体淡入替代遮挡

## CU02 · 眼神与手势引导注意力

- **资产：** 参见组件蓝图 UI02,UI03,UI05
- **动作：** 角色看向目标 → 目标出现或变化 → 角色反应 → 视线回收
- **空间与连续性：** 面部/身体/目标三个可独立控制的坐标层
- **检查：** 角色不与目标同时做大幅动作，眨眼避开信息首现

## CU03 · 对象错峰弹出并稳定

- **资产：** 参见组件蓝图 UI05,UI06,UI09
- **动作：** 预留空位 → 单个对象入场 → 小幅过冲收束 → 下一对象
- **空间与连续性：** 共同基线与组内节奏
- **检查：** 完成后稳定，不能持续震荡；关注体积与节奏差异

## CU04 · 连接、调用与状态传播

- **资产：** 参见组件蓝图 UI05,UI10,UI11
- **动作：** 对象先建立 → 连线或信号出现 → 目标激活 → 共用状态
- **空间与连续性：** 起终点附着对象，不让连线漂移
- **检查：** 有语义的起点和终点；描线并非证明实际执行

## CU05 · 角色留场、讲解对象换位

- **资产：** 参见组件蓝图 UI01,UI02,UI05,UI11
- **动作：** 旧对象退场 → 角色与界面留场 → 新对象接入 → 注意力转向
- **空间与连续性：** 固定世界空间，交接位置有连续性
- **检查：** 不需要每次闪白或铺满圆；不要留下无意空拍

## CU06 · 群组收缩并保留角落上下文

- **资产：** 参见组件蓝图 UI04,UI05,UI11
- **动作：** 群组成立 → 非重点淡出 → 主设备缩到角落 → 新任务进入
- **空间与连续性：** 保留主设备身份和已建立方向
- **检查：** 缩小后只作定位，不把不可读文字当信息

## CU07 · 焦点退场与背景工作台保留

- **资产：** 参见组件蓝图 UI01,UI02,UI06,UI08
- **动作：** 界面细节减弱 → 主角色/标签清晰 → 概念成立 → 返回操作
- **空间与连续性：** 背景仍是同一工作台，前景字幕不随镜头
- **检查：** 降低对比与适量虚化不同；不要把所有层一起模糊

## CU08 · 全貌到操作特写再返回

- **资产：** 参见组件蓝图 UI01,UI15,UI18,UI21
- **动作：** 全貌定位 → 缩放靠近目标 → 停稳 → 操作 → 返回全貌
- **空间与连续性：** 缩放中心围绕目标，保留至少一个定位锚点
- **检查：** 移动过程文字可暂略，停稳后的关键操作必须清楚

## CU09 · 点击反馈与控件状态联动

- **资产：** 参见组件蓝图 UI15,UI16,UI18
- **动作：** 指针靠近 → 短停 → 点击环/轻音 → 控件改变 → 反馈
- **空间与连续性：** 指针尖端命中实际控件
- **检查：** 控件先后态真实对应；不能只有点击特效

## CU10 · 逐位输入保持固定版式

- **资产：** 参见组件蓝图 UI13,UI17
- **动作：** 获得内容 → 对应输入区 → 逐位出现 → 完成确认
- **空间与连续性：** 固定字格与基线，内容增长不造成整行抖动
- **检查：** 代码完整可读，演示不泄露真实账户资料

## CU11 · 左右方案建立并比较

- **资产：** 参见组件蓝图 UI08,UI11,UI12,UI06
- **动作：** 同时建立两个选项 → 同维度说明 → 局部强调 → 选择理由
- **空间与连续性：** 左右身份固定，冷暖辅助区分
- **检查：** 不把未选项完全抹掉，以便比较；选择后再收束

## CU12 · 请求到工具再到可见产物

- **资产：** 参见组件蓝图 UI13,UI21,UI22
- **动作：** 请求内容 → 执行工具/状态 → 成品出现 → 正视阅读
- **空间与连续性：** 同一任务、名称和内容身份
- **检查：** 结果要有真实设计；黑色终端不是必需，因果才是核心

## CU13 · 局部修改与状态回证

- **资产：** 参见组件蓝图 UI13,UI15,UI18,UI22
- **动作：** 明确目标 → 用户动作 → 可见状态变化 → 成功确认
- **空间与连续性：** 保留未改区域，变化只在目标范围
- **检查：** 原片开关/授权反馈迁移为 Demo 日程修改；不是声称原片有同样日程镜头

## CU14 · 步骤逐项出现与完成

- **资产：** 参见组件蓝图 UI23,UI09
- **动作：** 第一项出现 → 完成保持 → 下一项 → 完整复盘
- **空间与连续性：** 稳定列表，不在每项后清空
- **检查：** 步骤数由内容决定；逐项完成应在新项目中逐一验证

## CU15 · 多伙伴分工、集合与组织关系

- **资产：** 参见组件蓝图 UI04,UI14,UI24
- **动作：** 组别出现 → 成员与职责对应 → 伙伴汇合 → 团队结果
- **空间与连续性：** 成员身份和组别对应，共同地平线
- **检查：** 集合之前必须表达各自负责什么

## CU16 · 回到主向导与品牌收束

- **资产：** 参见组件蓝图 UI01,UI02,UI06,UI07
- **动作：** 群体/任务退后 → 主向导回中心 → 简短主张 → 品牌保持
- **空间与连续性：** 回收开头的向导与界面，结尾留呼吸
- **检查：** 品牌不抢末句，音乐尾部完整；不强行沿用关注话术
