# 背景、受光与主体层级

背景应回答“内容处在什么视觉环境中”，帮助观众看清操作与结果。用户指出一念协作、DataTalk v3 的背景不够合适、有质感后，本例同时修订底色、光场、卡片边缘和阴影；仅替换渐变不能解决主体与背景混在一起的问题。

## 选择环境

| 内容 | 适合的起点 | 注意事项 |
|---|---|---|
| 多步骤软件与协作 | 当前默认明亮中性工作空间，少量品牌色用于状态 | 避免品牌色染满背景，让网页与图片失去自身颜色；小字需要独立对比度 |
| 数据、报告与知识 | 白或浅灰底，细微冷暖关系，轻阴影 | 轴线、图例和零值比装饰光斑更重要；不把阴影加在数据条上造成尺寸误读 |
| 实物、材质与硬件 | 根据材质安排灯、反光板、遮光与接触影 | 高光必须解释形体；需要折射与反射时使用真实几何与渲染器 |
| 广告与活动 | 与主张一致的纯色、图形或环境 | 不默认把所有场景都套成柔光灰色摄影棚 |
| 网站循环与界面反馈 | 静态环境或可闭环的光场 | 检查循环首尾、文字所在区域与实际网站底色 |

## 操作顺序

1. 先在灰度中检查标题、主卡片、次级内容和背景四层。背景最亮的位置应服务主体，不在无内容角落制造第一视觉焦点。
2. 定一个主要受光方向，再决定卡片亮边与投影方向。宽光源产生软阴影；紧贴表面的物体不应带很远的重影。悬浮距离变化时同步调整阴影，避免像粘在底图上的滤镜。
3. 再加温度差与品牌色。背景允许较低饱和度；状态、选择和主要按钮占用高彩度。底色不必与产品品牌色相同。
4. 光场可以由原生渐变、模糊形状和预合成完成。光带必须足够宽且不露硬边；在关键结果到达时缓慢变位，阅读段停住。无叙事作用的持续扫光会分散注意力。
5. 细颗粒只在需要时加在背景内部。优先低强度、固定种子、无动画，避免覆盖细字。检查实际 MP4 压缩后的噪点、色带和闪烁；原始 PNG 好看并不保证压缩后同样稳定。
6. 对照旧版，分别检查输入、中间过程、结果和收尾。深底、浅底、插图和数据页不能只审同一帧。保持已经成立的状态、图表尺度与声音标记。

## v3.1 原生案例

`assets/background-staging/` 是历史 `assets/task-results/` 的轻量修订，二者需共同保留。重建器先复制 v3 的素材、声音与真实交付物，再覆盖新视觉源码；不修改历史案例。

```bash
python3 assets/background-staging/rebuild.py --out /absolute/new-case/source --render
```

- **一念协作**：石墨底 `#45494B → #101418`；宽幅暖反光与软暗边；任务卡和工作面改为中性炭灰，边缘亮线与更宽柔影分开定义。ROAM 的内容与照片保持原有颜色。
- **DataTalk**：中心近白 `#FCFCFA`，边缘冷灰 `#D9DEE5`；白色窗光与低强度暖反光；报告卡片有轻离面阴影。图表仍使用同一基线、比例和渠道色，不把材质处理施加到数据编码。
- **收尾**：钴蓝背景由单色改为有明暗层次的色场；保留既有报告到品牌的转场时刻。
- **实现**：原生 Gradient Ramp、Gaussian Blur、Add Grain、Drop Shadow、矢量描边与独立预合成；所有图层可编辑。背景颗粒速度 0、种子 37。细节参数来自该案实际出图，不能作为所有引擎和分辨率的通用预设。
- **色深**：新建工程从 8 bpc 切换并读回 16 bpc。交付 H.264 仍为 8-bit，不把内部色深当成 HDR 或 10-bit 成片。

参考已有 Apple Liquid Glass 样帧中的浅色环境、接触影，以及 Claude 样帧的主体层级；本轮仅观察静态样帧。没有据此声称其制作软件、精确缓动或声音设计，也没有复制品牌素材。此处柔光是二维视觉构成，不能替代真实玻璃与金属的物理渲染。

## 验证边界

完整解码、帧率/时长、音轨信号与关键帧审看分别记录。背景预合成在阅读段两个时刻输出应稳定，可用像素差确认颗粒没有自行闪动；动作段的光场变化是有意设计。若声音未改，比较旧新音频字节或解码后 PCM；这可证明音轨沿用，不能替代主观听审。审美是否适合当前品牌还需要实际观看与用户反馈。

## 九条路线后续美术返修

v9 针对字幕近黑、主体与背景不协调的用户反馈，将色彩角色、构图、受光与字幕一起处理。软件主界面周围建立亮度层次，空间资料保持完整可读；品牌路线分别保留强节奏色场、暖纸编辑和有限色带；硬件拆解重新布光并保留透明底片的真实接触影。具体步骤、淘汰的过曝试渲及字幕例外见 [色彩、环境与字幕统一](color-environment-captions.md)。历史深灰案例仅作资料，不能覆盖当前浅色偏好。
