# 全长声音审查与返修

声音审查分四种证据：最终文件测量、实际发声转写、音频模型的听感判断、人工监听。逐项记录，不能把前一种写成后一种。当前代理若收到“audio input unsupported”，不能用播放命令或文件存在冒充自己听到了声音。可调用真实接收音频的模型协助审查，并明确标为模型辅助听审；人的音箱、耳机和现场监听仍是另一个验收项。

本流程不指定必须使用 Qwen 或任何第三方平台。历史案例的远程 Demo 是可替换的辅助工具，不是渲染、导出或 Skill 使用的付费前置条件。若当前没有获授权的实际听审通道，继续完成本地测量与字幕核对，将完整听审记录为待完成；不把它写成已经通过，也不把一般听审要求理解为对任意外部上传的授权。

## 先确认审查的确读取了声音

1. 针对最终 MP4 导出完整审听副本，保持全长，不只查开头几秒。记录原文件 SHA256、时长、审查模型、实际输入范围和返回文本。远程审听只使用本任务授权的素材与服务；敏感客户素材不能默认上传公开演示服务。
2. 第一遍不给配音稿，让模型逐句转写，并描述实际音乐、旁白情绪、停顿、尾音和明显问题。完整转写与实际采用的文本吻合，才支持它确实处理了声音；“没有收到音频”、只复述提示词、空响应或失败不计入覆盖率。
3. 再看全长音视频输入，检查声音与画面题材、动作、片尾的关系。模型可能内部抽帧，不能据此声称看过每一帧或验证两帧级误差。
4. 对疑似错读、哼唱、剪口或音效，回到独立语音、原始配乐和相邻区间复核。乐器名称只是模型判断，无法确定时用音色/节奏描述，不把猜测写成事实。
5. 记录问题是否采纳及理由。模型会把画面宣传语误认成底部字幕，也可能把弦乐或合成音误认成人声。用原生字幕图层、帧和原轨交叉检查，不能照单全改。

最终结果应至少包含：本批所有片子是否均有有效的全长返回、逐句文本核对、问题位置、原版证据、修订措施、新版复核、尚未执行的人工监听。外部服务成功生成一段回答不等于检查通过。

## 配音自然度

- 听完整句和上下文，检查停顿、重音、情绪、语尾、吞字、重复字、机械拼接感。中文字符/秒只用来定位过密句，不给自然度打分。
- 软件旁白应口语化，描述当前可见结果。例如“文件支持与更新方式，都有出处”可改为“支持哪些文件，怎样更新，都能找到依据”。具体功能仍须有画面和资料支撑。
- 结构拆解片的旁白对应部件与关系，不直接搬用材质微距片的“在光里看见精密”。保持已选音色，按句重录，保留旧 take、生成参数和进程退出记录。
- `IndexTTS2 --emotion-text` 是情绪映射，不是精确语速或播音风格控制。听审不通过时改措辞、停顿或重新生成，不宣称传了“自然”参数就自然。

## 音乐与场景

先定义声音任务：软件片给阅读和操作留空间；动态字体片可推动重拍；克制品牌片保留停顿；光学材质片强调连续和柔和；结构片强调稳定、清晰与少量机械声。不能因为同属一个领域就复用所有配乐。

MiniMax 的提示词、节拍、乐器和时长都是生成意图。逐条检查实际成品：是否提前结束、是否含疑似哼唱、是否偏忧伤/悬疑/游戏感、是否遮住旁白。先选合适的音乐，再做剪辑。失败候选保留为过程记录，不放进最终素材选择表。

需要纯器乐时，`[instrumental]` 使用真实换行；该标签不是无声乐保证。确有残留人声时优先重选/重生成；已安装的分轨工具可以制作去人声候选，但必须复核水声、相位、乐器损伤和残留，不能只看文件名 `no_vocals`。

AUREL 字形雕塑案例中，旧配乐的响度与峰值通过检查，用户仍指出音色与画面不搭。v2.1 重新比较柔和钢琴与明快木质器乐，并减少动作音；说明音色适配必须独立判断。钢琴不是通用高级感，复古芯片音也可以服务明确的游戏/复古品牌。实际选择与完整制作方法见 [字形雕塑＋动态排版](sculptural-type.md)。

## 节奏、剪接与收尾

- 以实际音轨的重音/乐句为依据，不能把提示词中的 BPM 当成测量结果。谱通量、波形和自相关可提供候选点，最后结合声音与画面复核。
- 主动作、转场、旁白语义重音和音乐不必全部机械对拍。优先保留阅读时间、正确的操作反馈和主要品牌落点。
- 音乐剪接记录源入/出点、交叉淡化、时间伸缩和选择原因。长交叉淡化不自动比短剪接高级；它可能叠出两个冲突节奏。需要变速时只处理配乐并保留音高，避免为了镜头时长加速配音。
- 结尾同时检查最后一句、最后一个音乐重音、尾响和视觉保持。淡出达到数字零不等于乐句结束自然。不要靠重复短音乐四五遍凑成长片。

## 字幕与混音

字幕采用最终选中配音的实际发声区间。检查首字前后、末字前后和相邻句边界，分别记录帧取整、首尾静音修剪和展示尾留白。本例使用句级字幕，不把它称为逐字强制对齐。

画面标题可比旁白先出现，或用另一种措辞表达同一主张；它不是字幕错误。底部旁白字幕必须与所读内容一致。保留透明背景；按每条路线与实际字幕区域设计颜色、字重和必要的细小边缘，见 `color-environment-captions.md`。

短片的两遍响度处理也可能偏离目标，尤其发生动态模式回退时。测最终 WAV 后再测实际 AAC，必要时小幅校正，并保留编码峰值余量。保留声像、单声道折叠、音量突跳、音乐避让、结尾余量检查。统计合格不能代替听感判断。
