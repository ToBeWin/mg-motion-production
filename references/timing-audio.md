# 转场、运动节奏与音画配合

按用户指定或已有配置选择配音与音乐；具体素材、字幕和检查流程见 [配音、音乐与字幕](voice-music-captions.md)。历史程序合成音乐保留为试制资料，不能默认当作新一轮商业目标的最终配乐。

## 共用时间轴

每个重要动作保存全局时间、动作语义、视觉锚点、效果类型、增益及可选声像。时间单位明确为秒或帧，换算使用项目 fps。动作开始、速度峰值、接触、完成是不同锚点。

```json
{
  "fps": 60,
  "duration": 12,
  "cues": [
    {"time": 3.0, "type": "click", "gain": 0.08, "anchor": "点击生成"},
    {"time": 3.15, "type": "whoosh", "duration": 0.6, "gain": 0.1, "anchor": "卡片展开，速度峰值约3.45s"},
    {"time": 6.4, "type": "chime", "gain": 0.06, "anchor": "进度首次到100%"}
  ]
}
```

这只展示字段。随片更新数值，不能把示例的 gain 当作归一化响度。声音素材自身的包络不同，文件开始并不等于听到的冲击点。可记录合成信号峰值辅助检查，最终仍需听审。

## 节奏设计

- 在序列层级分出开场、发展、对比、释放和片尾。给主动作一段完整弧线，不要始终全速。
- 在对象层级选择对应物性的曲线。无过冲的缓出适合多数 UI；轻微过冲适合弹性形态；机械动作强调限位与停顿。不能只换 easing 名称就宣称质感提升。
- 在相邻镜头层级保持速度、方向、重心或形态中至少一个连续关系。切点前后各一帧，以及切点前后 0.1–0.3 秒，都要检查。
- 快速运动可采用时间采样的运动模糊。示例默认每帧 3 个样本、约 180° 快门；这是效果与计算量的折中，不是必须参数。过长快门会糊字，不能掩盖跳变。
- 保留节拍与视觉错落：配乐小节帮助组织大段落，微动作可在节拍前建立期待或节拍后落定。不要为了对拍牺牲阅读或真实产品反馈。

## 配乐、效果与混音

先确定音乐性格，再为有限的关键动作配声。不要重复叠加多个高频点击、低频冲击和 whoosh。一个有分量的主声配一层安静质感通常比复杂堆叠清晰。

品牌版可强化弹跳与形变的拍点；产品版常需削弱鼓点和装饰声，为操作和完成提示留空间。适度 duck 配乐约 1–3 dB 可作为起点，但以素材和听感决定，不对所有音效自动压低整曲。

导出 music / sfx / voice（若有）独立轨。若承诺分轨可还原混音，则共享线性增益、同起点、同长度；非线性母带压缩或限制器应另附母带链设置，不能把各分轨单独归一化后声称能相加还原。

检查声道、采样率、起止、突跳、直流、削波、LUFS 与 true peak。示例以约 -16 LUFS、峰值留余量为工作选择，交付平台另有规格时使用其要求。AAC 编码后的峰值可能改变，应测最终 MP4 音轨。

原始合成音色适合可靠试制和可复用示例，不自动等同于商业录音质感。高要求项目还要音色挑选、空间层次、混音和实际播放/听审。音色来源、外部音乐许可和配音授权按实际素材记录，避免无依据承诺。

完整听审与生成配乐的实际节拍、词句、候选淘汰和误报处理见 [全长声音审查](listening-review.md)。本轮不再从提示词推定实际 BPM；短片响度在母带和 AAC 两个阶段复测。
