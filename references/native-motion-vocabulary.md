# 软件发布片的 MG 动作方法：不止交互和引导

与 [原生交互与注意力引导](native-interaction-fidelity.md) 配套。交互解决可信度，整条片子的字排、形态、空间、遮挡、节奏与收束决定它是否成为 MG 发布片。用户已明确要求四条软件路线增加更多 MG，不能将后续制作缩减为鼠标、点击环和箭头。

## 本轮已经做进原生工程的动作

| 动作 | 作用 | 原生实现与限制 |
|---|---|---|
| 动态字排 | 建立主张、改变密度、制造重音 | 独立字形错峰位移、行视窗裁切；字保持等比，停稳后阅读 |
| 形态接替 | 将一个文件入口连接到完整结果 | 同点数形状遮罩从文件行扩大成窗口；是片内转场，不假装产品实际采用这个动画 |
| 前景遮挡与擦入 | 让成果接力，保留空间锚点 | 原生 Linear Wipe 与持续底层窗口，按到达时刻剪接，防止露底 |
| 页面分层扇出 | 用多个实际成果形成有识别度的广告画面 | 页面独立预合成、3D Layer、Y 轴旋转、Z 位置与原生相机；没有重新建模玩具道具 |
| 空间推拉与重新排布 | 从单个成果进入能力集合 | 同一页面实例从近景移动至网格，统一比例与透视，阅读时回到正面 |
| 错峰编排 | 显示关系、制造节奏，而非所有对象一起出现 | 命名时间点、位置/尺度/旋转关键帧；高密度展开后保留整组停顿 |
| 结构展开 | 让工作成果从一件变为一组 | 六个实际结果按阵列出现，保留来源与内容对应；不能把同一个文件复制六次冒充六种能力 |
| 汇聚与品牌接力 | 将能力回收到产品身份 | 原实例收拢成小叠层，再由用户的原始官方标识接住画面；不重画或自造 Logo |
| 音乐留白与重音 | 给纯 MG 段落呼吸空间 | 保留连续音乐乐段，旁白之后安排成果展开，关键落位绑定声音 cue |

可编辑源码：`assets/native-interaction/source/effectcraft/motion_vocabulary.jsx`；交互、引导与镜头基础在同目录 `interaction_library.jsx`。源配置中的 `motion_stage` 提供开始/结束、主张、实际文件与名称，`motion_events` 记录声音落点。

## 四种风格的区别应体现在动作上

- **实证式产品发布**：问题字排与真实请求交接，操作打开结果，成果通过方向性擦入接力，最后一项持续缩入矩阵。重点是案例证明及由慢到快的结构节奏。
- **图形组件产品发布**：大的价值字排、文件行到整页的形态接替、浅透视纸张扇出、正视网格，再汇聚到品牌。空间反差较强，正文正视阅读。
- **柔光工作台**：任务锚点与窗口保持连续，单页让位给两列成果空间，页面错峰展开、回正与汇聚。重点是关系清楚和有层次的留白，不以持续漂浮代替运动设计。
- **指针导览**：真实操作与步骤引导后，进入连贯的成果序列；文字、连接路径、独立页面与品牌收束配合。向导只承担注意力的一部分，不能占据全部 MG 表现。

这些是本轮 1080p30 的具体实现，不意味着风格只能使用这些方法。新片可按题材继续研究路径形变、重复器阵列、图形循环、切分重组、局部粒子、跟踪合成和更复杂三维，但必须有对应设计需要和实际渲染证据；不能把可调用的效果名称写成已经达到的成片能力。

## 编排与精度

1. 每个段落确定主动作，以及离开时交给下一段的对象；优先设计对象接力。
2. 区分阅读、运动和集合三个尺度。小矩阵用于辨认结构，正文在先前近景阅读，标签以最终画面像素设计。
3. 前景可挡后景，但不要在阅读段遮核心结论。展开中短暂遮挡用于说明层级，落稳后要恢复清楚。
4. 检查组件、文件页和标签是否真正匹配。例如预算页不能标为团队分工，不能因为版式相似就错配素材。
5. 收拢、旋转和透视回正要使用统一父级/预合成坐标。连接线应跟随对象，或在对象离开前退场，不能留下悬空路径。实际查看中段，不能只看动画端点。
6. 运动模糊只用于快速段。渲染采样、曲线、遮罩边缘和图像清晰度一起检查，不能靠长快门掩盖跳动。
7. 先做能说明本片价值的一组动作，再增加变化；更多 MG 不等于在同一画面持续堆特效。
