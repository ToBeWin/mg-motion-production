# 能力验证与交付边界

区分规划、设计资产、连续预演、实际导出、画面检查、完整听审和用户验收。可编辑工程或静帧检查不能证明整片已完成或已获验收。

场景和风格由 `assets/scenario-catalog.json` 管理，六种通用原生组件见 `assets/scenario-components/`。输入、指针、引导、阅读及结果交接方法见 [原生交互](native-interaction-fidelity.md) 和 [跨风格增强](cross-style-mg-enhancements.md)。真实产品需使用获得授权的素材并核实每个操作与结果。

所有新项目都应重新验证接口可用性、路径、字体、清晰度、声音和最终交付；不把以往案例结果推断为任意项目的质量保证。
