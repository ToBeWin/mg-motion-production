# 热烈品牌｜Bold Brand Pop

风格 ID：`bold-brand-pop`。关键词：放晴、SUNPOP、热烈品牌、强色场、巨幅字体、包装主视觉、产品与图形混合。用户看过《放晴 SUNPOP｜把今天，打开。》后反馈“可以，这个做另外一种风格固化到skill中吧”，本路线记录这条风格的正面反馈与收录决定。

## 选用与迁移

适合以品牌性格、情绪记忆和产品外观为中心的广告、品牌宣言、社交短片与发布会开场。`bold-type` 是通用的大字与节奏几何方法；本路线从一套完整品牌资产出发，让字标、产品、包装和图形拥有共同的色彩与运动性格。真实产品可以进入图形世界；没有实体产品时，可用原创字形、插画或品牌符号承担主体，不必添加三维。

SUNPOP 是虚构品牌，饮料罐、太阳、橙蓝配色、三条短口号和 24 秒时长都是本例选择。新任务使用本次指定的品牌；要求新概念时重新命名并设计资产，不自动继承案例身份、文案和题材。用户希望发挥想象力时，从品牌性格与一个能持续变化的图形命题开始，不必先选行业编号。

| 新题材 | 可迁移的设计与动作 | 需要重新解决 |
|---|---|---|
| 食品、饮料与消费品 | 包装图案成为母形；开启、旋转或挤压形成动作起点 | 标签、食品/液体尺度、材质与真实产品依据；不能复制本例罐体或编造功效 |
| 运动、潮流与生活方式 | 鞋纹、织物、标识或速度方向成为运动语言；摄影与图形穿插 | 原创造型、影像来源、接触与重量；柔性织物和硬物各有运动物性 |
| 文化、旅行、活动品牌 | 地方形态、字形或插画建立识别，再以图案展开与汇聚 | 文化语义、内容来源与图形统一；不必使用实体商品或三维模型 |
| 科技与数字品牌 | 用品牌符号、设备或原创视觉系统表达品牌态度 | 若任务是功能发布，补充真实输入与结果；情绪广告不能代替功能证据 |
| 社媒、片头与舞台开场 | 大字、色场、母形与声音重拍适配观看距离 | 独立重排画幅、字阶、阅读时长和最终品牌识别；循环片另做首尾接缝 |

这些是迁移方向；本例实际完成的是横屏饮料品牌片，不把表中的所有题材和载体写成已制作、已验收样片。

## 设计资产与运动语法

1. **先完成品牌资产。** 至少设计一张能独立成立的关键画面，以及本片实际需要的字标、图形、包装/产品或插画。确定字体、背景、主体、强调与字幕的色彩角色。把真实标签内容、曲面贴图范围、字形间距和最终展示尺度一起考虑，不能等动画完成才补设计。
2. **少量元素形成多种状态。** 母形可以是太阳、弧线、切口、纹样或定制字形。明确它在包装、图形、标点与转场中的身份和变形规则；用单独主体、局部特写、全屏图案与品牌落版改变密度。新品牌可以采用其他色系与母形，强烈不等于每帧都高饱和、满屏或闪动。
3. **文字与主体共同构图。** 巨幅字排可以有意裁边、遮挡、被产品穿过或形成前后空间；品牌名与关键口号仍需有完整可读状态。普通字幕保持正常比例。不要把随机弹跳、持续漂浮或所有字同时缩放当作本路线的全部运动。
4. **按对象设计物性。** 真实金属罐体保持刚性，图形可以弹性回落，字体冲击应有预备、落点与停顿。三维镜头用真实连续相机/物体运动和变化的反射揭示轮廓；一张渲染图平移不等于连续三维动画。只在需要时引入模拟或复杂材质。
5. **给转场一个携带物。** 例如产品动作带出图形，图形扩大接入文字，标签或轮廓接到下一色场。接替时保留至少一项形态、颜色、方向或构图关系；检查过渡中段的露底、错误裁切和空拍。快段之后留可辨识的停稳段，结尾让品牌持续可读。

## 工具组合

需要可复用版式与组件时使用 Figma；需要精确包装、路径和轮廓时使用 VectorCraft；位图、摄影或纹理需要独立处理时使用 PhotoCraft。工具是否参与以实际操作为准，不为凑齐应用清单添加环节。SUNPOP 本轮设计由 VectorCraft 完成，Figma 没有设计写入。

产品材质段可用 Blender 建模、UV、灯光与连续动画，再以透明中间片交给 EffectCraft；图形、字体、父级运动、缓动与遮挡尽量保留原生图层。SUNPOP 使用 Cycles/Metal、三套原创标签和 ProRes 4444 透明片；这是一条已验证组合，不是所有项目都必须用的引擎或格式。

设计文件与动画源码保持同一身份和色彩规则。原始字形/路径、贴图、打包纹理的模型、声音分轨与构建脚本一起保存。需要剪辑交接时提供 FilmCraft 或 FCPXML；结构校验和 CLI 导入与目标剪辑软件的 GUI 播放验收分别记录。通用交接见 [设计工具链](design-toolchain.md)。

## 声音和字幕

按本次用户选择配音与音乐。纯音乐广告可以作为主版本；加入配音时使用适合品牌性格的短句，保留必要的同步字幕及无字幕版。不要让旁白占满每个动作段，也不把本例的三句台词作为固定配方。

- 按**实际生成结果**挑音乐。SUNPOP 第一条候选偏卡通管弦乐，与目标不完全匹配，最终换为第二条放克/迪斯科方向。提示词里的曲风、BPM 和“自然结尾”不构成结果证据。
- 先找到主要动作与音乐重音，再安排开启、触碰、气泡和转场音效。身体动作的声音跟随动作；只有重要图形变化需要声标。这里的小型程序化音效用于触感，没有替代最终配乐。
- 配音段让音乐让位，检查最后一句后的恢复包络，避免临近片尾突然抬高。SUNPOP 最终保持片尾避让，并在 21.0–23.6 秒以余弦曲线渐弱，留 0.4 秒尾段；这些数值仅描述该 24 秒案例。新片按实际乐句选择结束重拍、混响尾音或淡出。
- 以实际语音起止驱动字幕；按每个色场选择字色并查看最终编码帧，不固定黑字、不默认加底板。主标题承担品牌设计，字幕优先清楚、同步、不遮主体。
- 模型听审的时间定位可能出错。本例一轮把 11.65 秒的配音误放到 7–9 秒；用实际分轨、波形和画面交叉检查，不照单采纳，也不以客观响度数据替代听感。最终完整音画与纯音乐另做审查，保留失败候选与修改记录。

具体生成、混音与全长审查沿用 [配音音乐字幕](voice-music-captions.md) 和 [声音审查](listening-review.md)。模型辅助检查不等于真人专业监听。

## 本例验证的工程细节

以下为 EffectCraft 0.17.0 / Blender 5.2.0 的本地实测；换版本时查看实际输出。

- **设置父级后重设局部坐标。** 本例先放置子图层再赋 `parent`，引擎保留了世界位置，太阳组件偏到了左上角。明确父级坐标后重新赋子层局部位置；不要只看分组是否存在。
- **先设 `startTime`，再确认 `inPoint/outPoint`。** 本例在设置入出点后修改开始时间，入出点也随之移动，造成产品在应出现的镜头里消失。设置素材偏移后再写入预期可见区间，并在实际出现时点渲染核对。
- **透明底片的边界也是画面边界。** 微距渲染中，拉环顶端原先超出源画幅；底片在合成里缩放、位移后，裁切边界露在屏幕中。修正三维取景与安全余量并重新渲染，不能用放大或平移掩盖。检查完整动画中的极端姿态和最终合成位置。
- **归档与重开必须读取真正的素材。** EffectCraft 媒体用相对路径，Blender 打包纹理；本例在新位置重开 22.5 秒帧与原图一致。剪辑交接文件移动目录后重新生成媒体地址；不能只验证旧工作目录仍在时可打开。

## 调用与源码

自然语言：“使用热烈品牌 `bold-brand-pop` 风格，参考放晴的包装、巨幅字体、产品与图形接替方法，按本次品牌重新设计。”

```bash
python3 scripts/choose_style.py --show bold-brand-pop
python3 scripts/plan_scene.py --scenario brand-manifesto --style bold-brand-pop \
  --title "本次品牌广告" --duration 30 --out /absolute/new-project/plan
```

规划后继续实际制作。30 秒只是调用示例；竖屏用 `--aspect 9:16` 规划并重新构图，不能把横片裁切当作完成适配。

完整案例：`assets/design-exploration/SUNPOP/`。

- 三个有声版本、无声画面母版、预览页、`case.json` 与历史检查。
- `source/design/create.py`、SVG / PNG / `.vectorcraft`：三套包装、字标、太阳组件和海报。
- `source/blender/sunpop.py`、三个打包纹理的 `.blend` 与透明 `.mov`：开罐、单罐、三罐连续镜头，共 435 帧底片。
- `source/SUNPOP.ecproj`、`source/effectcraft/sunpop.jsx`、`source/build.py`：原生文字和形状动画、合成与三种有声版本；工程共 146 层，含 137 层主画面。
- `source/audio/`：三段语音、两条音乐候选、最终分轨与母版、SRT、时间轴和生成记录。
- `editor-handoff/`：FilmCraft 与 FCPXML；`review/`：最终 720 帧完整解码、AAC 测量、字幕边界、模型音画审查与原生重开证据。

复制到新的项目目录再修改。`design-system.json` **不是全片的自动换品牌接口**：字标、标签、主体模型、动效文案和声音分别在设计、Blender、JSX 与音频源中，需要共同重设计。`source/build.py --render` 重建合成；`source/editor_handoff.py` 为新目录生成剪辑交接。

本次用户同意收录的是这一风格。交付时状态保存在 `review/case-at-delivery.json`，当前收录决定在 `case.json`；不改写原有媒体检查为所有行业、画幅、自动换品牌或旗舰品质已验收。
