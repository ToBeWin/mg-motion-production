# MG 风格选择

风格与用途交叉组合。精确产品 UI 适合表达控件和反馈；空间界面适合展示内容之间的空间关系；动态排版适合突出主张；光学材质适合真实材质与产品细节；二维插画适合解释流程；数据地图需要保留比例、单位和来源。

针对软件与 AI：

- **图形组件产品发布**：独立设计任务、文件和结果组件，用字排、路径和遮罩接替，关键结果保持可读。
- **柔光工作台**：保留持续任务或窗口锚点，以窗口让位、局部操作和结果并置建立关系。
- **指针／角色导览**：定位 → 操作 → 反馈 → 阅读 → 复盘；可以仅用指针，不要求角色。
- **实证式产品发布**：少量完整任务展示深度，后续巡览成果展示广度，再以成果集合与品牌收束。
- **目标成行**：同一目标贯穿结构、阶段、时间和成果。
- **设计展开**：让一个可识别的设计对象连接编辑、主题和输出。
- **编辑式产品叙事**：在大字与产品细节间变化，持续展示输入、修改和交付。

品牌与硬件也可使用热烈品牌、字形雕塑、混合媒介、金属玻璃、实拍增强等路线。先设计有辨识度的资产，再确定尺度、节奏和声画，不通过堆叠特效代替叙事。可使用选择器查阅全部 22 条路线。
