# 角色与指针导览：组件与状态

下列是可组合设计蓝图；角色、界面、配色和时间按本次项目重做。

## UI01 · 持续工作台

- **图层：** 外框、标题、侧栏、主内容、输入区、资料区
- **状态：** 完整 → 局部聚焦 → 退为背景 → 恢复
- **空间锚点：** 世界坐标中的窗口与侧栏
- **检查：** 降低非当前区域对比；操作时恢复清晰；空间位置不能随意跳变

## UI02 · 主向导身体与手势

- **图层：** 轮廓、主体色、高光、左手、右手、地影
- **状态：** 探出 → 招手 → 指向 → 等待 → 确认 → 收束
- **空间锚点：** 身体中心，手势为局部坐标
- **检查：** 先有意图再有动作；地影随高度与尺度；角色不能遮挡目标

## UI03 · 眼睛与视线

- **图层：** 左眼、右眼、共同面部父级
- **状态：** 睁眼 → 眨眼 → 转向 → 思考 → 愉快
- **空间锚点：** 面部父级跟随身体但有独立视线偏移
- **检查：** 视线指向当前讲解对象；眨眼避开刚出现的关键信息

## UI04 · 彩色伙伴与分工身份

- **图层：** 伙伴轮廓、面部、身份标签、对应工具标志
- **状态：** 进入 → 结伴 → 领任务 → 离开 → 集合
- **空间锚点：** 主角色与任务对象的关系坐标
- **检查：** 不能只换颜色，身份和任务需要对应；不能将头像并排当成协作

## UI05 · 工具或能力图标

- **图层：** 白色承托、工具图形、名称、状态徽章
- **状态：** 空位 → 出现 → 激活 → 已连接
- **空间锚点：** 共同底线或组中心
- **检查：** 按放大倍率设计描边与角；真实品牌用授权原标志

## UI06 · 语义标签与小胶囊

- **图层：** 背景形、语义图标、短文字、软影
- **状态：** 出现 → 强调 → 稳定 → 退出
- **空间锚点：** 目标附近，预留字幕与角色位置
- **检查：** 标签说属性或状态；避免按钮式标签被误当可点击控件

## UI07 · 旁白字幕与关键词

- **图层：** 文本、关键词色、可选浅色底板
- **状态：** 短语进入 → 保持 → 替换 → 结束
- **空间锚点：** 屏幕坐标，独立于工作台缩放
- **检查：** 按真实发声对齐；当前用户默认透明底；不照搬原片底板

## UI08 · 语义光晕与环境色

- **图层：** 低频背景色场、局部光晕、保护文字的前景层
- **状态：** 中性 → 聚焦 → 冷暖对照 → 退场
- **空间锚点：** 跟随对象或分区，明确各自空间
- **检查：** 不能用低对比雾气盖住正文；颜色承担角色或选项语义

## UI09 · 强调环与短射线

- **图层：** 圆环、独立射线、淡出包络
- **状态：** 聚焦 → 扩散 → 消失
- **空间锚点：** 目标中心，不跟随无关相机
- **检查：** 一次强调后停稳；数量和半径按主体尺寸设计

## UI10 · 调用路径与连接线

- **图层：** 起点、曲线、端点、点状信号
- **状态：** 未连接 → 描出 → 传递 → 连接完成
- **空间锚点：** 端点附着具名对象的同一坐标系
- **检查：** 连接线必须有语义方向；目标移动时端点不能脱离

## UI11 · 全天电脑与云端承托

- **图层：** 显示器外壳、屏幕、支架、24h标记、云形承托
- **状态：** 开机 → 执行 → 安装工具 → 完成
- **空间锚点：** 屏幕与设备共同父级，内容独立遮罩
- **检查：** 数字和状态保持可读；无需为固定视角小图标强行三维建模

## UI12 · 本地笔记本与设备屏幕

- **图层：** 外壳、屏幕、底座、屏内软件、文件或身份标记
- **状态：** 空闲 → 已连接 → 确认弹层 → 执行
- **空间锚点：** 屏幕四角与外壳共享投影
- **检查：** 内容跟随设备透视；不要让屏内文字变成无意义纹理

## UI13 · 请求输入框与消息

- **图层：** 输入面、文字、提交按钮、附加内容、收到状态
- **状态：** 编辑 → 提交 → 执行 → 反馈 → 再次修改
- **空间锚点：** 左侧输入基线，提交点固定
- **检查：** 输入与后续产物相符；不能只打字而没有结果

## UI14 · Bot 条目与资料侧栏

- **图层：** 列表行、身份图标、名称、选中底、资料面
- **状态：** 新增 → 选中 → 切换 → 资料更新
- **空间锚点：** 侧栏稳定，选中状态与主区一致
- **检查：** 不保留上一角色资料却切到另一个角色；避免列表全屏漂移

## UI15 · 设置或授权面板

- **图层：** 面板、真实设置项、动作按钮、状态说明
- **状态：** 打开 → 聚焦 → 操作 → 确认 → 关闭
- **空间锚点：** 围绕当前操作点建立镜头
- **检查：** 真实产品授权边界按产品事实；示意面板标注概念

## UI16 · 双态开关与确认控件

- **图层：** 轨道、滑块、标签、状态色、点击反馈
- **状态：** 关闭 → 点击 → 开启 → 完成
- **空间锚点：** 滑块在同一轨道，标签不换位
- **检查：** 视觉状态与系统动作一致；不能用彩环替代开关变化

## UI17 · 链接与验证码格

- **图层：** 链接、验证码、输入格、当前格、成功态
- **状态：** 获得 → 打开 → 逐位填写 → 成功
- **空间锚点：** 固定字格与基线
- **检查：** 演示用示意内容；真实账户和一次性码不要作为可复用资产

## UI18 · 指针与点击反馈

- **图层：** 指针、目标控件、点击环、状态结果
- **状态：** 靠近 → 停稳 → 点击 → 反馈 → 离开
- **空间锚点：** 指针尖端对应真实命中点
- **检查：** 音效、点击环与状态变化同拍附近；点击不能落在空白处

## UI19 · 文件夹、文档与清单道具

- **图层：** 封面或文件夹、页、内容行、标签、勾选
- **状态：** 出现 → 展开 → 内容形成 → 保存
- **空间锚点：** 封面转轴、页面共用画布
- **检查：** 对象要有具体含义；纸张与字不能穿过封面

## UI20 · 钥匙与礼物等语义道具

- **图层：** 主体轮廓、高光、局部部件、语义标签
- **状态：** 进入 → 展示 → 交给对象 → 退出
- **空间锚点：** 主角色手边或讲解目标旁
- **检查：** 只在解释权限或额外能力时用；不把随机礼物当转场模板

## UI21 · 终端与执行状态

- **图层：** 窗口、代码或选择列表、焦点行、执行状态
- **状态：** 打开 → 选择 → 执行 → 成功或失败
- **空间锚点：** 正文可读区域，镜头跟随当前操作
- **检查：** 保留真实含义和错误状态；不编造运行成功

## UI22 · 网页、图表、图片等结果

- **图层：** 结果容器、独立设计内容、状态、编辑入口
- **状态：** 生成 → 显示 → 阅读 → 修改 → 分享
- **空间锚点：** 与请求内容同一身份，阅读时正视稳定
- **检查：** 结果不是空白占位；新项目必须重做可信成果

## UI23 · 步骤复盘与逐项完成

- **图层：** 数字标记、步骤行、状态色、勾选
- **状态：** 等待 → 当前 → 完成 → 全部总结
- **空间锚点：** 稳定行高和顺序，完成行保持
- **检查：** 逐项确认，避免过快；复盘与实际教学步骤一致

## UI24 · 团队分组与伙伴集合

- **图层：** 分组标题、成员行、状态、主角色、伙伴群
- **状态：** 浏览 → 高亮分组 → 展开 → 集合 → 收束
- **空间锚点：** 分组固定，集合沿共同地平线
- **检查：** 先展示分工，再集合；各伙伴规模与层次有目的
