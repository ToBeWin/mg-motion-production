# 目标成行｜动态字排与进程叙事

## 选择与区别

| 相近路线 | 主要注意力 | 何时选择本风格 |
|---|---|---|
| `editorial-type` 极简编辑字排 | 信息层级、比较与阅读 | 需要让一个关键词或数字持续变成后续内容，而非只做字级与图表对比 |
| `bold-type` 强节奏大字 | 品牌态度、节拍与视觉记忆 | 需要讲清目标如何推进，阅读与证据比强拍冲击更重要 |
| `spatial-ui` 空间界面 | 层级、空间与多资料关系 | 主要关系是拆解、顺序、时间或责任，平面字排和路径已能解释清楚 |

没有结构或进程关系的单一功能，不必硬套时间轴；纯材质展示、角色故事通常另选风格。本路线不要求所有镜头都做数字动画。

## 不随品牌变化的表达方法

- **同一对象推动叙事。** 在分镜中写出“出镜对象 → 动作 → 下一状态 → 继续承载的信息”。例如大号增量数字缩小移动成为客群段标题，目标条分成有名称的组成部分，进程线接到交付文件。避免旧对象消失后用无关卡片重启。
- **字排有动作，也有完整的阅读状态。** 用数字卷轴、短语错峰、遮罩和位置/尺度变化；内容展开后停稳。单位、目标/实际标签和数据口径随对象保持。滚动数字只是入场，不暗示真实增长。
- **阶段节奏看得懂。** 有可靠时长时，时间段长度与天数成比例；游标沿节点推进，放在信息外侧。只有顺序、没有时长时，标为步骤，不画成暗示比例的时间轴。
- **回到真实证据。** MG 负责解释；真实输入、界面、方案或产物负责证明。明确区分图解与实际软件画面，原始文件可留在交付工程中。
- **品牌与声音完整收束。** 使用目标产品真实 Logo 和本次适用的品牌文案；有旁白的版本，为片尾配音、字幕和尾音留出时间。案例中的口号不作为通用文案。

## 每个项目重新确定

先用 computer use 或已有可信实操材料理解产品，检查其 Logo、主题色、输入与结果；旧材料是否仍有效按本次任务判断。选择要解释的一条主关系，再设计动作。

可选叙事顺序是“目标/任务 → 输入与关键动作 → 结构展开 → 进程/责任 → 实际产物 → 品牌”。按内容删减、合并或重排；没有责任分工就不加预算/团队段，没有真实交付文件就展示实际可验证的结果。

## EffectCraft 原生实现要点

| 方法 | 具体做法与已遇到的问题 |
|---|---|
| 数字卷轴 | 独立预合成裁剪字列，按位错峰滑动，最终读数由实际数据确定；保留单位和性质标签 |
| 大数字转为段落标题 | 同一文字图层改变位置与等比缩放，配套标题稍后进入；检查中文和数字的实际字形边界，避免基线跳动 |
| 结构展开 | 图形与文字分别组织或用遮罩揭示整个预合成；不把整个文字卡片纵向压扁来“制造 MG” |
| 带文字的标签 | 背板与文字放入同一预合成或共享父级，整体入场；分别错峰移动会让文字滑出背板 |
| 短横条变竖向分隔 | 先缩为短条/点、旋转、再伸展。直接同时插值宽高会出现大矩形；直接旋转长条可能扫过标题 |
| 图文证据换页 | 新图放入不透明、大小匹配的容器，用遮罩逐步接替，旧图保留到遮罩覆盖完成；仅“旧图切掉＋新图从零透明度进入”会出现空白闪断 |
| 分带转场 | 覆盖阶段保证画面全闭，内容在遮挡下切换，再错峰离场；控制使用频率，不能每段都靠同一种擦除掩盖缺少连续关系 |
| 进程线与游标 | 用原生路径修剪和关键帧；游标避开段落名称和数值，停留段检查空间曲线是否漂移 |
| 证据容器 | 以可用宽高双重约束等比适配；核对边缘、标题、来源说明与字幕，不能只按宽度缩放导致上下溢出 |

字体、形状、遮罩和路径优先由原生图层控制。需要其他工具时按画面目的选择，不以效果数量或工具品牌判断质量。

## 声画与质量检查

旁白对应当前可见的目标、阶段或结果；节点可有克制声标，不必每块内容都加音效。若用户要求一首连续音乐，整段使用，仅做必要的响度与首尾处理。音频提供者、是否复用、原始分轨和本次检查范围分别记录。

审看实际编码成片中的展开中段、数值落位、标题接力、证据换页与最后一句，不能只看各段静止终态。确认没有文字拉伸、单位错位、游标遮字、边缘穿帮、短暂空白、品牌旁白被切断。完整解码、转写、响度与主观听审分别记录；结构检查通过不等于用户对新品牌成片的认可。

## 调用与案例

```bash
python3 scripts/choose_style.py --show kinetic-process
python3 scripts/plan_scene.py --scenario business-process \
  --style kinetic-process --title "本次产品的计划到交付" \
  --duration 38 --out /absolute/new-project/plan
```

38 秒仅演示 CLI 参数，不是该风格默认时长。场景仍决定素材和证据链；规划器会附带本风格指南、检查项和已认可案例。生成的是制作规划，仍需完成本次资产、动画与声音。
