# 三个领域都提供多种风格

用途决定内容，风格决定表达。三条主片分别覆盖正常软件发布、明亮金属硬件、强节奏品牌字排；六条 8 秒研究扩展不同构图与运动方式。原九条研究保留；另加入已获用户方向正面反馈的“目标成行”和“FOLD｜设计展开”，以及用户要求收录的“编辑式产品叙事”“热烈品牌”和“字形雕塑＋动态排版”，另有参考复现研究“柔光工作台与成果叙事”，在“高能混合媒介产品发布”研究基础上，新增用户认可的“图形组件产品发布”后，加入角色导览与实证式产品发布后，目前软件 11 条、品牌 5 条、硬件 3 条。路线数量不代表同等成熟度，也没有把 24 类用途全部重新精修。

## 新任务怎样选择


```bash
python3 scripts/choose_style.py --domain software
python3 scripts/choose_style.py --show hardware-optical
```

每种风格至少独立确定：字体、色彩角色、背景空间、运动物性、相机用途、转场携带物、音乐性格、信息密度。只改背景色、字号、速度或换一个产品名，不算新路线。

## 可以继续扩展的方向

软件可扩为开发者编辑器、数据编辑排版、移动端触控、影像与界面混合；品牌可扩为摄影拼贴、插画、角色、实验字形；硬件可扩为哑光软材料、实际使用情境、实拍与三维混合。现有 20 条视觉路线提供制作入口，但这些组合没有因既有路线自动获得成片或质量验收。

## 声音同样按路线区分

v8 增补了逐条声音复核：软件用清楚、口语化的功能说明；工程拆解用部件与层级文案；字排品牌按实际配乐重拍编排；克制品牌、流动曲线与光学材质分别选择短钢琴或连续的明亮器乐质感。不是九条都铺同一首音乐，也不要求每条都强节拍。最终音视频模型审查覆盖九条，人工监听与客户验收状态单列。

## 背景与主体的配色

三领域分别定义环境、主体、强调、次级信息和字幕角色。v9 在九条现有路线中修正色彩搭配，并重点重做空间工作台、流动品牌与硬件结构的背景和层次；各路线具体决策见 [色彩、环境与字幕统一](color-environment-captions.md)。保留不同路线的设计差别，不把所有场景做成同一种淡色渐变。
