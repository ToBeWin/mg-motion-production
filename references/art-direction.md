# 视觉方向与资产深度

风格不是一个滤镜名称。它需要字体层级、色彩角色、材质、空间尺度、形态和运动习惯共同成立。下列路线可组合，但要有主次；不要平均混用。

| 方向 | 应先做好的资产 | 有效的表现重点 | 合适用途 |
|---|---|---|---|
| 极简编辑 / 动态字体 | 字体、字重、字距、短文案、基线 | 词义驱动的揭示、尺寸对比、精确停顿 | 品牌主张、发布片引子、社媒 |
| 精确产品 UI | 真实产品状态、操作与结果 | 焦点、光标、选区、微反馈、状态连续 | 功能发布、开发工具、教程 |
| 明亮空间 UI | 精修界面、分层布局、接触阴影 | 透视/视差服务关系，正视阅读有足够时间 | 软件平台、AI 工作台、协作 |
| 光学 / 材质 | 可信材质、厚度、环境与反射形状 | 宏观与微观尺度、控件形态、光的连续 | 设计语言、硬件、高端品牌 |
| 精确技术 | 有意义的结构图/数据、明确对比层级 | 明亮中性底、语义色、层级与精确推进；深色仅在用户另有指定时考虑 | API、基础设施、安全、研究 |
| 人文纸感 / 编辑拼贴 | 插画、照片、纹理、编辑式排版 | 手工节奏、遮罩与轻微非机械变化 | 教育、文化、创作工具 |
| 活力几何 / 插画 | 母形、完整造型语言、比例规则 | 有重心的弹性、语义形变、图形节奏 | 消费品牌、年轻化产品、科普 |
| 数据 / 科学 | 校验过的数据、标尺、图形编码 | 从数据点到关系和结论，运动保持尺度 | BI、研究、金融、技术解释 |
| 目标成行 / 动态字排与进程叙事 | 本次目标/任务、可解释的阶段关系与真实产物 | 同一数字/关键词转为结构，遮罩揭示、时间轴和责任推进 | 软件方案、Agent、业务流程；见 [专门指南](kinetic-process.md) |
| 影像混合 / 电影化 | 实拍或高质量生成影像、3D、合成资产 | 真实世界动机与数字界面联系 | 生活助手、硬件、创意 AI、品牌 |

## 判断一帧是否已经设计完成

先看关键画面能否独立成为合格的产品广告图。字体回退、信息密度、主次、对齐、留白、影调、素材质量是否成立？高分辨率渲染不能修复版式薄弱。UI 中少量真实细节比大量灰色占位线更可信，但细节不能与主价值竞争。

制作关键画面时写清：主信息、允许观众阅读的次信息、只作环境的细节。三者不能拥有相同对比度和动作量。字体要在最终渲染中检查中文、英文、数字；Web/Canvas/CJK 的同名假设经常导致错误字形。

## 声音也需要视觉方向

材料与动作应有相符的触感：轻纸、柔软界面、坚硬金属、空间穿越不宜全配同一种 whoosh。音乐提供结构和情绪，音效提示关键状态；给重要落点留空间，不把每个元素都配成一次重击。概念阶段可以用原创合成器预演，精修音乐仍需实际听审。

AI 可用于生成形象、纹理、背景或概念帧。可读文字、产品状态、数据逻辑和精确变形最好由可控图层/几何实现。由目标决定混合方式，不因某种工具可调用就让它承担不合适的部分。
