# 三个场景，三种动作逻辑 · v11

这组样片接续用户认可的 TRACE v10 连续动效方向，制作 SHIFT 品牌动态字体、ORBIT 科技硬件反馈、一念协作产物汇聚三个不同解法。它们是虚构产品/品牌概念片；不代表实际 AI 服务调用、量产硬件或品牌官方作品。

| 项目 | 成片 | 重点动作 | 可编辑内容 |
|---|---|---|---|
| SHIFT | 18 秒，1920×1080，30fps | 双斜杠扩成遮挡；轮廓字展开；几何波次换场；字内纹样；切片字形合拢 | 字体、轮廓路径、遮罩、纹样、图层变换、分轨与字幕 |
| ORBIT | 16 秒，1920×1080，30fps | 旋钮转动带动 24→80 的示意亮度；弧线拉直为标尺；同一线条回收为 O | Cycles 产品/灯光/转角；反馈路径、读数、字幕、声音 |
| 一念协作 | 18 秒，1920×1080，30fps | 文案、照片、色块与布局分别产生，再连续进入同一个 ROAM 网页 | 同一图层/资产的前后状态、照片随动字色遮罩、页面与字幕 |

每条交付烧录中文字幕和不烧录字幕版本；两版均含声音。SRT 在各自 `audio/<case>/captions.srt`。字幕是原生文字层，使用本场景的蓝、蓝灰或灰绿，不带不透明底板。

## 从新目录重建

需要 Python 3.10+、本地 EffectCraft CLI、FFmpeg。原生画面使用 macOS 的 Hiragino Sans GB、Helvetica Neue 和 Menlo 字体。换系统、字体或引擎版本后应重新检查字宽和换行。

```bash
python3 rebuild.py --out /absolute/new-project/source --render
python3 rebuild.py --out /absolute/new-agent/source --case agent --render
```

输出目录必须不存在，影片写到其父目录。默认采用包内最终混音和透明三维底片；不联网，不调用 TTS，不产生音乐服务费用。`--remix` 使用包内选定的声音素材重新混音，需要 NumPy；它不会重新生成配音或背景音乐。`EFFECTCRAFT_CLI` 环境变量可以覆盖 CLI 路径。

单独修改后，在自己复制出的工作目录执行：

```bash
python3 audio/mix.py --case agent
python3 build.py --case agent --replace-project --render
python3 verify_source.py --out ../qa/source-audit.json
python3 qa_media.py ../一念协作_v11_从想法到作品_中文字幕.mp4 --out ../qa/media
```

`--replace-project` 只用于明确要重建的工作副本。不要指向旧交付目录。

## 三维重渲与反馈

ORBIT 使用 Blender 5.2.0 LTS / Cycles / Metal、48 samples、1024² 透明 RGBA。保留原始模型 `blender/ORBIT-base.blend`、本次调整后的 `ORBIT-control.blend`、生成代码和实际选用的透明 ProRes 4444 底片。

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --python blender/render_control.py -- --render
python3 blender/encode_plate.py
python3 build.py --case hardware --replace-project --render
```

渲染器面向 Apple Silicon；换硬件时需设置可用的 Cycles 设备。更改模型、相机、灯光或采样参数后，使用新的 `frames` 目录，不复用旧 PNG。脚本只重算变化姿态并复制相同姿态的停留帧。

`data/hardware-motion.json` 的同一组 120 个转角样本用于三维关键帧与原生读数。60° 转动映射到 24→80% **只是功能表达示意**，不是传感器测量、照度标定或真实产品参数。底片从成片 2.8 秒开始，最后姿态延长到片尾；产品不等于静态截图。

数字层单独关闭运动模糊。原生反向 Alpha 遮罩使数字越过弧线时仍清楚；弧线退出经画面上方移动，再成为标识，避免从产品实体中间穿过。

## 声音与内容来源

配音使用已选择的本地 IndexTTS2 合成声：SHIFT 与 ORBIT 重剪此前生成的片段；一念协作本轮新生成四句，再剪去首尾静音。新配音的生成记录见 `audio/agent/generation-audit.json` 与 `raw/`；声音参考为用户已有的合成音色，并非特定真人。未打包模型或音色参考；默认重建复用选好的音频。

三条配乐都来自本项目此前实际选用的 **MiniMax Music 3** 音轨，分别重剪节奏、收尾及人声段的压低量。本轮没有重新请求 MiniMax 生成。硬件与协作使用此前筛选的器乐/人声分离结果；SHIFT 对原曲做保音高节奏调整。选段、来源 SHA-256、复用状态、声效落点在每条 `edit-plan.json`。音效为既有事件素材，不以简单合成旋律替代音乐。

ROAM 的同一原创 AI 风景图、海岸路线文案、选中状态与配套 HTML 保持一致。视频是为阅读重排的 MG 页面，并非浏览器像素录屏。`deliverables/ROAM/checks-prior-v3.json` 是旧版检查记录；v11 只做源码、资源与内容一致性检查，不把旧记录当作这次浏览器验收。

## 检查与限制

实际检查在交付包 `qa/` 和 `审看与交付说明.md`：完整解码、实际 AAC 测量、原生字幕边界、关键画面和密集转场抽帧、全长模型辅助声音/画面审查、新目录工程重建与选定帧一致性。

模型辅助审查不是人工耳机监听；抽帧不是全帧人工播放；重建选定帧一致不等于另一次完整 Cycles 渲染。现有官方案例的学习方法可迁移，但不据此声称本轮又完整看过最新发布片，或这三条已达到各品牌旗舰品质。
