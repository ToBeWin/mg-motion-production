# 三条主片与六条风格研究 · v9 美术与字幕修订

本包优先制作正常软件发布，同时为软件、品牌与科技硬件分别提供三条不同风格路线。主片和短研究的完成层级不同；九条路线不等于九支同等成熟的旗舰发布片。

| 主片 | 结构 | 规格 |
|---|---|---|
| TRACE v2 / 每一步有据 | 完整软件工作台、输入问题、定位原文、形成答案、回看来源 | 28 秒，1920×1080，30 fps |
| ORBIT v4 / 光与精密 | 金属微距、光学表面、轮廓、整机与品牌 | 20 秒，1920×1080，30 fps |
| SHIFT v2 / 让下一步发生 | 字形动作、斜切转场、原生三维字体、字内图案与品牌 | 20 秒，1920×1080，30 fps |

六条研究均为 8 秒：软件编辑排版、空间工作台；品牌克制字排、流动曲线；硬件光学玻璃、概念结构展示。风格目标与适用场景见 `style-routes.json`。

## v9 美术变更

本版针对字幕接近黑色，以及背景、主体和配色不协调的反馈：按九条路线配置独立字幕颜色；软件环境与界面投影共同调整；空间工作台重排资料与主界面；品牌分别采用暖纸、有限色场和环绕字标的同色系曲线；硬件拆解以中性银色重新布光，保留真实接触影并合成到浅色环境。具体可编辑字幕配置在 `caption-themes.json`；它同时支持逐句例外，不能将浅底和金属暗部套成同一种颜色。

声音、语句内容与时点沿用 v8；发布导出直接复用 v8 AAC，实际包数据一致性在 `qa/render-provenance.json`。本轮没有重新生成声音，也没有新增全长听审。此前模型辅助听审记录保存在 `qa/previous-v8/`，其文件哈希属于 v8。

## 编辑与重建

需要本机 EffectCraft CLI、Python 3/NumPy、FFmpeg。重新渲染 ORBIT 的三维摄影或重新制作结构研究的灯光底片才需要 Blender；当前完整底片已随工程提供。字体使用本机 Hiragino Sans GB、Helvetica Neue、Georgia、Menlo，未打包字体文件。字体缺失时先验证替代字形与宽度，再重做布局。

```bash
python3 rebuild.py --out /absolute/new-project/source --case trace --render
python3 rebuild.py --out /absolute/another-project/source --case all --render
```

复制脚本拒绝覆盖已存在目录。四个 `.ecproj` 可直接打开，主片和研究保留可编辑的图形、文字、遮罩、重复器、关键帧、3D 平面和相机。主片各有无烧录字幕与中文字幕合成；研究交付带字幕版。

在工作副本中，重建六条研究：

```bash
python3 build_styles.py --replace-project --render
```

重建声音或摄影：

```bash
python3 audio/make_sfx.py
python3 audio/mix.py --raw audio/raw
python3 audio/mix.py --raw audio/raw --styles
python3 build.py --case orbit --render-3d --replace-project --render
```

在受限执行环境没有 Metal 设备时需要主机渲染权限；不要把 CPU 草稿结果当作 GPU 成功。`--cpu` 可用于临时验证。渲染新的三维底片会耗时，且输出在本副本的 `blender/frames/`。默认 Cycles 64 samples、自适应采样、降噪、AgX、1920×1080；原始 PNG 为 8-bit，不能据此声称 HDR。四个硬切点相邻的 8 帧关闭运动模糊，避免快门采样跨越不同相机位置产生重影；本机 Blender 的该布尔属性不可动画化，因此由逐帧渲染脚本设置；场景自定义属性记录这些帧。手动渲染时也要执行此切点规则。

## 配音、音乐与字幕

本轮保留 21 句 IndexTTS2 原始配音，最终九条样片共采用其中 20 个不同 take；3 句为本次重录。实际选用 5 个 MiniMax 音乐 take，按不同场景选段、处理与混音；其余候选保留为筛选记录。`audio/audio-direction.json` 保留原文、情绪、音乐方向和初始时点；`audio/raw/` 保留实际采用的生成文件、日志与路由记录。旧的程序合成背景音乐没有进入本版交付。

配音只修剪首尾静音，不截断语句、不默认加速。每个 `audio/<case>/timeline.json` 记录实测时长、使用增益、起止与音乐剪接区间。具体选择和剪接见 `audio/editorial-mix.json`。TRACE 保留原钢琴乐句并去除声乐残留；ORBIT 采用新材质配乐的器乐分轨；三个短研究采用新的短钢琴乐句，工程片采用新的电声节奏。SHIFT 的配乐按实际重拍候选重新剪接，使用保留音高的轻度变速，配音未加速。`audio/processed/` 保存经听审的器乐处理版本与来源哈希。

混音分轨：`voice-edit.wav`、`music-edit.wav`、`sfx-edit.wav`。母带前混音和处理链分别在 `premaster-final.wav`、`timeline.json`。最终母带 `master.wav` 为 48 kHz 双声道；目标约 -16 LUFS，实际 AAC 指标见检查记录。分轨是母带前电平，不能未经母带链直接相加声称还原最终母带。

字幕是按句从实际修剪后声音生成，非逐字强制对齐。主片提供不烧录字幕与中文字幕 MP4、SRT；原生工程内也有可编辑字幕；字幕背景透明，不使用圆角白色底板，软件画面为字幕预留独立空间。所有版本保留同一份声音。

若需重新生成，先读本机的 `local-tts-router` 与 `minimax-music3-local` Skill，确认现有模型和参考来源。`audio/generate.py` 只调用已安装工具，不下载模型；新的配音参考通过 `--voice-reference` 明确传入，新输出目录通过 `--out` 指定，避免覆盖 take。该入口生成基础候选；生成新音乐后必须重新筛选并更新 `editorial-mix.json`，不能把新候选自动视为本版已选素材。使用本包既有素材重建无需再次生成或下载模型。

## 重建硬件结构底片

默认用随包 `media/orbit-structure-v9.mov`，带真实接触影的透明 ProRes 4444 底片，源 PNG 为 8-bit RGBA；不能据此声称 HDR。需要重新布光时：

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python blender/relight_structure.py -- --preview 136 --samples 64 --scale 100
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python blender/relight_structure.py -- --render --samples 64 --scale 100
ffmpeg -framerate 30 -i blender/structure-v9/frames/%04d.png -frames:v 240 -c:v prores_ks -profile:v 4 -pix_fmt yuva444p10le -alpha_bits 16 media/orbit-structure-v9.mov
python3 build_styles.py --replace-project --render
```

保留既有几何、相机与时间。原片 3–11 秒的 240 帧对应这条短样；仅在前后邻帧的刚性场景状态完全相同且渲染种子固定时复用静止帧，记录在 `blender/structure-v9/static-frame-reuse.json`。修改灯光或材质后请清空本次生成的帧缓存，或在新项目目录渲染，不能沿用旧缓存。

字幕检查：`python3 qa_caption_design.py --frames` 读取原生的文字、颜色、字体、时间和图层数量，并逐句生成关键帧；审美接受仍需实际审看。

## 产品与素材的范围

TRACE 为原创软件概念。`deliverables/TRACE产品原型.html` 根据关键词从三份示例资料中检索，显示引用并下载答案 JSON；不调用在线 AI 或后端。影片、原型与资料来自同一 JSON。原型有 Node 逻辑验证，浏览器视觉和实际交互仍需单独审看。

ORBIT 与 FORM 为原创硬件概念。结构研究展示分件，不代表制造级 CAD、实际性能或真实产品发布。光学与结构研究复用本项目历史原创三维底片及模型。

官方参考片用于研究构图、材料与信息组织，没有复制其标识、镜头或音轨。v8 九条 MP4 共 116 秒曾完整送入 Qwen3.5-Omni 做模型辅助声画听审，并核对返回中的 29 句旁白。模型内部如何抽帧不公开，因此不宣称逐帧主观观看。

本轮记录在 `qa/final-media-report.json`、`qa/audio-sync-report.json`、`qa/caption-design/report.json`、`qa/visual-review-v9.json` 与 `qa/render-provenance.json`：分别对应完整解码/音轨测量、原生字幕与声音边界、29 句应用后的配色、实际关键画面审看范围，以及音轨沿用的哈希核对。
