# 本轮纠偏与旧样片定位

用户指出“很多实际偏离了，没有达到 MG 视频的效果”。这轮先修正制作方向：上一轮过多注意背景、材质与字幕的静态协调，有些样片更接近界面演示、动态海报或材质摄影，连续图形叙事与运动组织不够。

本次实际完成 **一条 16 秒 TRACE 软件 MG 方向验证片**，两个导出版本（中文字幕 / 不烧录字幕）。旧九条完整保留，并没有全部重做。旧版 TRACE 为 28 秒，预览中供整体比较，两条结构与长度不同，不作同时间码的 A/B 同步对照。

## 这次改变了什么

同一输入条收成问题条；资料错开展开；两段原文带着编号沿分离路径进入答案；点击引用后回到同一原文；焦点括号与引用点最终成为品牌图形。变化承担信息的交接，阅读时停稳。保留明亮背景、蓝紫色字幕，没有字幕底板。

实际修正了摘录交叉、副本过早出现导致叠字、原文底板遮挡标题和来源名称，以及焦点线扫过文字的问题。制作细节与重建方法见 `source/制作说明.md`。

## 九条原有路线怎样保留

| 路线 | 更准确的用途与后续重点 |
|---|---|
| TRACE 主片 | 软件操作与证据链；新 v10 单独验证连续 MG 动作 |
| 软件编辑式 | 信息排版研究；需要补足独立的动态叙事 |
| 空间工作台 | 空间层级研究；需要增加文档状态变化与产物交接 |
| SHIFT 主片 | 动态字体与母形转场；继续精修字形阅读和节奏 |
| 克制品牌 | 动态海报与短循环；不能直接代表完整品牌发布片 |
| 流动品牌 | 曲线视觉研究；让形变承担更明确的品牌含义 |
| ORBIT 主片 | 精密材质与产品摄影；作为硬件片的重要镜头资源 |
| 光学短样 | 玻璃与光学材质研究；需与功能或图形叙事结合 |
| 结构短样 | 分件与结构说明；继续加强部件变化与标注配合 |

这是本地制作诊断，不是用户对每条的逐项评分。用户此前认可的玻璃、金属材质方向继续保留。

## 实际检查

- 两个最终 MP4 各完整解码 480 帧；1080p30、16 秒，Rec.709。
- 最终 AAC 实测 -16.25 LUFS、-2.09 dBTP；两版音频数据相同。
- 五句 IndexTTS2 选段与 MiniMax Music 素材按新时间线重新剪辑混音，没有重新生成。
- 最终带字幕片全长模型辅助声画审查；五句旁白转写与内容一致，模型未报告明显杂音、残留歌声或剪接断点。细微同步仍以实际时间线和画面为准。
- 最终带字幕片 28 点抽帧、四处转场 64 点密集抽帧；无字幕版另有 4 点抽帧。抽帧审看不等于全片逐帧人工播放。
- 五处原生字幕文本、配色与整帧边界检查；两组指定摘录对象碰撞区间检查；新目录重建并比对原生输出帧。

模型辅助审查、信号测量、视觉审看与用户验收分别记录。没有进行人工耳机/音箱监听，也不据此声称达到海外大厂旗舰标准。这次先验证 MG 制作方向，后续质量判断以影片与用户反馈为准。

这条仍然偏软件 UI 信息片，视觉重心仍在白色资料卡与工作台。最终辅助审查也将其描述为“固定版面加漂移配合信息转场”。连续对象与几个关键转场已实做，但这不能证明图形张力、镜头变化和品牌辨识度已经达到用户所要求的精品 MG 水平。不能只摘取审查中关于声音的正面结论来宣称整片验收。
