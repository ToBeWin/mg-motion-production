# AUREL v2.1 · 声音重配

用户反馈：「背景音乐感觉有问题」，随后明确为「音色和风格不搭」。本版替换音乐并重新混音，原版 v2 独立保留。

## 风格与应用

画面属于「字形雕塑 + 动态排版」：同一组路径在三维实体、文字载体与留白空间之间变化，强调品牌识别、比例和形态记忆。

| 场景 | 适配方式 |
|---|---|
| 品牌发布、品牌焕新、Logo 片头 | 围绕真实字标或品牌母形重做路径与构图，突出记忆点。 |
| 创意 AI、设计软件发布 | 把母形接到画布、图层、工具状态和真实作品；当前案例是品牌气质段，不是功能证据。 |
| 科技硬件、工业设计 | 以实体材质和部件关系衔接产品展示，可用作开场或片尾。 |
| 发布会、展会、官网开屏 | 大字、清晰轮廓和少量文案适合短时观看；循环或竖屏需要单独重排。 |
| 建筑、文化活动、设计工作室 | 将字形构形用于空间、主题字和展览视觉。 |

复杂功能讲解、教程和客户案例仍需要真实界面、操作过程及结果证据，不能仅用抽象字形替代内容。

## 本次声音选择

旧配乐的主导音色带复古游戏感。两条新候选都由本机 MiniMax Music3 MLX q6 生成，30 steps，保留请求、原 WAV 与完整听审记录；生成提示词只是意图，实际音色以声音审查为准。

- 主配乐：`minimax-aurel-v21-chamber.wav`。实际以柔和钢琴为主，声音更安静、舒展，带自然延音。原始生成约 17.14 秒；采用开头 16 秒，保留原速，并处理尾部渐弱。并未宣称生成了真实录制的钢琴或完整弦乐。
- 对照配乐：`minimax-aurel-v21-organic.wav`。实际是明快的木质敲击／类似木琴的音色与持续铺底，性格更轻巧，适合更活泼的创意工具或年轻品牌方向。
- 转场提示由八处减至四处，降低其存在感。音乐在原 IndexTTS2 两句旁白期间避让。
- 配音原始 stem、句子起止时间以及全部编码画面保持一致。有配音时保留原同步透明字幕。

2026-10-29 用户要求将「字形雕塑＋动态排版」固化到 Skill。本例现以 `sculptural-type` 登记于 MG Skill 3.18.0，补齐适用场景、制作流程与配乐注意事项；未将这次收录扩展为所有音色获得单独评分或全部场景达到旗舰质量。原交付时的状态与说明保存在 `review/case-at-delivery.json` 和 `review/at-delivery-制作说明.md`。

## 观看与工程

打开 `打开配乐对照.html`，可切换钢琴配音字幕版、无字幕配音版、纯音乐版，以及明快器乐对照版。所有视频为 16 秒、1920×1080、30fps。

- `source/AUREL-v2.ecproj`：v2 画面工程，音频资源已更新到本次主配乐；六个合成、30 个图层，含原生路径动画及字幕。
- `source/blender/`：两份原生 Blender 项目与透明 ProRes 连续底片。
- `source/design/`：VectorCraft / SVG 及共享路径参数。
- `source/audio/`：旧生成记录、新候选原始音频、当前主配乐、旁白和效果分轨、最终母带与 SRT。
- `review/audition-organic/`：对照音乐的混音与时间表。
- `editor-handoff/`：当前主版本的 FCPXML / FilmCraft 交接。

## 重建

```sh
python3 source/audio/mix.py
python3 source/build.py --preview --render
```

以上用已生成的当前音乐重建主版本。`source/audio/mix_v21.py` 支持选择候选曲及独立输出目录。`source/remux_sound.py` 是保留编码画面的快速换音轨路径，当前使用包内画面源，不依赖旧版同级目录。可用 `--out /absolute/new-output` 输出到新目录；如需额外核对历史 v2，显式传入 `--baseline /absolute/v2-delivery`。新检查写入 `review/remux-check.json`，保留历史报告。

原生工程使用相对媒体路径。重新排字需安装 `source/fonts/` 中实际使用的字体。影片音频及三维底片已随包提供，不必重新运行本地模型。模型路径和原生工具路径沿用本机安装配置。

## 已检查的范围

`review/picture-and-voice-preservation.json` 记录了四个主交付视频的画面流 SHA256 与 v2 完全一致，旁白 stem 逐字节一致。因此本次没有重新进行三维渲染或把未改的画面当成新制作。

实际 MP4 完整解码均为 480 帧，配音字幕版音轨约 -16.01 LUFS / -2.43 dBTP，钢琴纯音乐版约 -18.44 LUFS / -2.23 dBTP。最终 AAC 末尾正常渐弱至接近静音。原字幕检查作为历史记录附带，其编码画面和语音时间均未变化。

对最终主配乐的配音版、纯音乐版进行了全长模型辅助音画审查，转写与两句原稿一致，未报告额外歌唱、明显语音遮盖或游戏音色。对照版也有完整混音源音画审查及最终文件解码检查。模型辅助审听不是人工耳机或音箱监听，乐器与情绪描述是其观察，不是客观审美评分。

FCPXML 通过本机 Final Cut Pro 随附 DTD 校验，并导入保存为 FilmCraft 工程；未声称已在 Final Cut Pro GUI 里人工完整重放。本次保留的画面来源及更早的设计提案、字体许可证均在源目录中。
