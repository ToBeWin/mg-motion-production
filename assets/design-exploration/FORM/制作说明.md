# FORM｜形的发生

18 秒原创 MG 探索，1920 × 1080，30 fps。以“线如何获得体积”为命题：描绘 → 扩展 → 光与材料 → 遮挡 → 字形。

打开「打开预览.html」选择纯音乐、配音字幕或无字幕配音版。所有版本具有相同画面结构；配音字幕版添加三处原生文字。纯音乐版保留原创配乐与动作音效，便于按自己的用途再组合。

## 作品与设计

- 0–5.1 秒：三条 Bézier 轮廓渐次描绘，以切线旋转、尺度和重心变化引入空间。
- 5.1–11.1 秒：圆形遮罩进入连续三维镜头；带厚度与倒角的陶瓷、淡铜、玻璃和青绿色曲面随相机运动改变遮挡与反射。
- 10.62–12.3 秒：色彩对应材质的斜向遮挡片覆盖画面，将空间交接给文字。
- 12–18 秒：四个原生字形错开运动、伸展和落位，最终形成 FORM 与“让想象成形”。

这是一支不预设应用的视觉实验。它不是任何现成品牌发布片的复制，未将用户验收或旗舰质量作为已完成结论。

## 如何修改

先把整包复制到新的项目目录，保护这次交付。

1. 路径与图形：在 VectorCraft 修改原生文件后导出 SVG。当前适配器只支持绝对 M/C/Z、无变换、无填充的纯色描边；它不是通用 SVG 导入器。运行 `python3 source/svg_paths.py source/assets/FORM-contours.svg source/assets/FORM-paths.json` 更新路径。
2. 背景：在 PhotoCraft 修改 pcraft 并覆盖副本中的 FORM-studio.psd；保留原有图层身份或重新执行 PSD 合成交接。进入 EffectCraft 后保留的是三个素材层，渐变调整参数仍在 PhotoCraft 源文件里。
3. 动画与字排：直接编辑 FORM.ecproj，或修改 source/effectcraft/form.jsx 后重建。主要颜色为暖纸色 F2EFE7、青绿 214E4B / 247A73、淡铜 DFAF85、薄荷 AFD7C6。
4. 三维：修改 source/blender/form.py 或 FORM.blend，重新渲染并替换 FORM-optical.mov。底片已有 180 个不同的真实三维帧；本包不包含可再生的 PNG 帧缓存。
5. 声音：修改 audio/mix.py 的句段、声音标记和包络，再运行混音与视频构建。已生成的原始配音与音乐均在包内，重混不需要重新加载模型。重新生成配音时按本机 local-tts-router Skill 检查音色来源，不把本片音色设为所有项目默认。

## 重建命令

需要 Python 3、FFmpeg 与 EffectCraft CLI。混音额外需要 NumPy。先进入本文件所在目录。

~~~sh
python3 source/audio/mix.py
python3 source/build.py --render
python3 source/editor_handoff.py
~~~

build.py 默认读取本机 ~/Library/Application Support/EffectCraft/bin/effectcraft-cli，跨机器可通过 EFFECTCRAFT_CLI 环境变量指定。完整底片已经包含；只修改二维、文字或声音时不必重跑 Blender。

需要重新生成三维时：在新的项目副本中运行，旧 frames 存在时会被复用，因此修改几何或采样后应使用新的空帧目录。

~~~sh
/Applications/Blender.app/Contents/MacOS/Blender -b -t 8 --python source/blender/form.py -- --render --samples 48
ffmpeg -y -framerate 30 -i source/blender/frames/%04d.png -c:v prores_ks -profile:v 2 -pix_fmt yuv422p10le -color_primaries bt709 -color_trc bt709 -colorspace bt709 source/assets/FORM-optical.mov
python3 source/build.py --render
~~~

Blender 本片使用 Cycles Metal、48 samples、AgX Medium High Contrast、降噪和 0.35 快门运动模糊。跨机器应先检查可用计算设备。

## 交接与字体边界

Figma 的 FORM 关键画面使用 IBM Plex Sans / Noto Sans SC；合成中的文字为有意重新编排的 Helvetica Neue / Hiragino Sans GB，未声称字形像素级无损迁移。矢量控制点独立保留。导出设计稿中复杂 SVG 阴影可能被 VectorCraft 忽略，不能把导入成功等同于效果兼容。

EffectCraft 工程中的素材为相对路径。FCPXML 与 FilmCraft 使用媒体 URI；移动整包后运行 editor_handoff.py 重新生成。FCPXML 通过本机 Final Cut Pro 1.10 DTD 检查，FilmCraft 实际导入且无离线媒体，重开渲染了 8 秒帧。尚未进行 Final Cut Pro 或剪映 GUI 的完整导入导出验收。

最终配音字幕版与无字幕配音版共享完全相同的 AAC 数据。EffectCraft 本次音频直接导出出现超限峰值，已改用校准母带统一编码。原生工程仍保留声音与字幕，可编辑。
